Agenda, vínculos com coleções, presença e comprovantes sobre o Events Manager gratuito.

== Description ==

Consulte LEIA-ME.md para instalação, uso, dependências, privacidade e limitações. Requer o Events Manager gratuito 7.4.13 ou mais novo, instalado como plugin separado a partir do diretório oficial do WordPress. O pacote de produção não inclui cópia dele. Tainacan não é instalado automaticamente.
