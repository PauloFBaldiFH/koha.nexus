# Gabay ng gumagamit ng Koha.Nexus

Ang siyam na kabanatang ito ay para sa pag-install at panel ng Koha.Nexus, hindi kapalit ng buong gabay sa katalogo at sirkulasyon ng Koha. Manu-manong isinulat mula sa Portuges at Ingles at inihambing sa code na 8c2633d. Ang pagbasa ng code ay hindi aktuwal na pagsubok sa pag-install. Pinanatili sa Ingles ang mga pangalan ng aksiyon upang maitugma sa code; maaaring isalin ang mga ito sa panel. Hindi isinasalin ang mga utos at landas. Basahin ang pagkumpirma bago magpalit o magbura ng datos. Huwag umasa sa lumang numero ng menu.

## Kailangang kumpirmahin

- Pampublikong availability at URL sa Microsoft Store.
- Opisyal na minimum na RAM sa Linux, na hindi ipinapatupad bilang numerong kondisyon sa paunang pagsusuri.
- Buong paggana ng MSIX sa ARM64; x64 ang manifest.
- Mga pribadong layout at bersiyon ng export na walang sample at pagsusuri ng resulta.
- Pagkakaroon at kondisyon ng mga panlabas na sanggunian mula sa lokal na network.
- RAM, disk at bilis ng tugon ng AI ayon sa hardware at pagpili.
- Domain, network at patakaran ng institusyon para sa paglalathala.
- Sanhi ng tiyak na pagkabigo kung walang buong mensahe at log.
