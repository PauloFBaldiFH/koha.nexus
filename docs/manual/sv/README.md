# Användarhandbok för Koha.Nexus

Handboken beskriver Koha.Nexus-installation och panel, inte Koha-systemets fullständiga katalogisering och cirkulation. Texten är skriven för hand från portugisiska/engelska och kontrollerad mot kod `d81eb64`. Kodgranskning är inte ett installationstest på riktig hårdvara.

Åtgärdsnamn behålls på engelska för exakt koppling till kodens nycklar; panelen kan visa översättningar. Kommandon och sökvägar översätts inte. Destruktiva åtgärder kan ersätta/radera data: läs bekräftelsen. ”Att bekräfta” markerar osäkerheter som koden inte ensam garanterar. Använd inte gamla menynummer.

## Att bekräfta

- Offentlig Microsoft Store-tillgänglighet och URL.
- Officiellt Linux-RAM-minimum, inte numeriskt framtvingat av förkontrollen.
- Fullständig MSIX-funktion på ARM64; manifestet är x64.
- Proprietära exportlayouter/versioner utan prov och resultatgranskning.
- Externa källors tillgänglighet och villkor från lokala nätet.
- AI-minne, disk och svarstid per hårdvara/val.
- Domän, nät och institutionens publiceringspolicy.
- Konkreta felorsaker utan fullständigt meddelande och logg.
