# 4. マジックインポート

[目次](README.md)

## 入力の準備

**Magic Import Tool** を i またはサイドバーから開きます。元ファイルと検証済み backup を保持し、複数所蔵、空欄、アクセント文字、例外を含む代表例から始めます。元システムとプレビューの件数を比較し、利用者情報は公開しません。選ぶパスは実行先 Linux から読める必要があり、ブラウザー端末のファイルが自動転送されるわけではありません。

MARC21 ISO 2709、MARCXML、テキスト MARC、MarcEdit `.mrk`、CSV/TSV、XLSX/XLS、ODS、DBF、表形式の JSON/XML/SQL を扱います。`.mrk` という理由だけの変換は不要です。任意の XML が MARCXML とは限りません。SQL はデータとして抽出し、プログラムとして実行しません。

ISIS の専用読取は `acervo` 表を含む認識可能な PostgreSQL 出力に対応します。CDS/ISIS `.mst` は直接読み込まず、WinISIS から ISO 2709 を出力します。Biblioteca Fácil は関連表を一緒に保ち、書誌、利用者、貸出、予約を別々に確認してください。Koha 全体の backup はデータベースを置換する restore に誘導されます。

他システムの PostgreSQL、特にバイナリ pg_dump は MariaDB 用の復元ファイルではありません。読めない場合は元システムで MARC か表形式へ出力します。アーカイブは各内容の判定を読み、PDF、写真、文書、実行ファイルを書誌出力として扱わないでください。

## 手動マッピング

**Bibliographic**、**Patrons**、**Authorities** の判定を確認し、誤判定なら切り替えます。サンプル表で各フィールドの保持、転送先、固定値、除外を確認します。識別子は表同士の関係に必要かもしれません。表の高さは仕切り、Ctrl+Up、Ctrl+Down で変更します。

**Values of this Koha** で館、資料種別、利用者区分の実在コードと既定値、値の対応表を調べます。**Record preview** はサンプル、**Check the whole file** は全体の準備・検証で、この時点では Koha へ取り込みません。プロファイルを命名して **Save**、選んで **Use**。構造が変わった出力には再確認が必要です。

**Apply** または Ctrl+S はマッピングを承認して準備を続け、最終登録の確認とは異なります。Esc／**Skip: import as it is** はマッピングを省略し、全取り込みを取り消す操作ではありません。一括文字変換や重複処理は、略語・固有名・コードへの影響をプレビューします。

## 所蔵・利用者・典拠

Koha の `952` は保全し、依頼した場合だけ有効な館・種別に対応付けます。既定と違うだけで有効なコードを置換しないでください。`949`、`852`、`950`、`990` は出力元によって意味が異なります。バーコード、所属・所在館、請求記号、種別、場所、受入日を照合します。`DL` を伴う法定納本注記だけで自館の現物を作成してはいけません。

欠落バーコードは原則として確認対象です。代替生成には明示的選択と安定した移行・出力元の識別が必要で、既存との衝突を無断採番し直しで回避しません。SQL の書誌と所蔵は内容と識別子で関連を確認し、列位置や行順だけを根拠にしないでください。

利用者は氏名、カード番号、連絡先、住所、生年月日、登録・期限、館、区分を個別に点検します。CPF、メール、日付の形は手掛かりであり確証ではありません。同形式の日付でも用途は異なります。カード番号一致の既存利用者更新と新規追加を区別し、権限や認証情報を推測で割り当てないでください。

典拠は識別子、標目、異形、関連、種別を確認します。モード変更で存在しない情報は作れません。

## 登録と結果確認

準備出力、件数、警告、拒否を読み、未解決コードや更新選択を確認して登録します。既存書誌の維持と新所蔵のみ追加、書誌置換、比較せず毎回新規作成は効果が違います。

後段の失敗は前段の取り消しを保証しません。部分登録を調べてから再実行を判断し、Koha の所蔵・利用者・典拠リンクを点検します。**Undo a MARC import** は MARC バッチ用で、利用者・貸出・予約の万能な取り消しではありません。特定製品の版や独自出力への適合はサンプルと結果レビューによる確認が必要です。
