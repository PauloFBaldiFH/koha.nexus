# 6. OPAC と staff の外観

[目次](README.md)

## 変更を小さく確認する

o または **OPAC and Staff Appearance** から開きます。一般向け OPAC と職員向け staff はそれぞれ設定があります。**Sync current OPAC settings** で現状を読み、項目群ごとに少しずつ変更します。同期は新テーマの適用ではありません。

**Preview** は書き込む CSS、JavaScript、内容を示し、ブラウザー全体の描画ではありません。**Apply** は backup を作成し、内容を確認後に反映します。その後は両方のホーム、検索、レコード、ログインと小画面の見やすさをブラウザーで試してください。

OPAC の `OpacUserCSS`／`OpacUserJS`、staff の `IntranetUserCSS` と必要時の `IntranetUserJS` に管理ブロックを書きます。独自ブロックは保全しますが、外部カスタマイズとの競合はあり得ます。透明度、ぼかし、素材、角、背景、アクセントと文字のコントラストを確認します。

staff の色、上部バー、簡易検索、カード、表密度、文字サイズは独立です。**Apply color theme to Staff Client** が有効化し、**Copy OPAC preset** は欄を埋めるだけなので適用には **Apply** が必要です。

## 画像と案内

画像はサーバーファイル、提示された画像ホスト、直接 HTTPS URL を選びます。PNG、JPEG、GIF、WebP、ICO に対応し SVG は拒否します。職員端末のファイルは先にサーバーから読めるようにします。掲載権とスクリーンリーダー用説明を用意し、ホストのページ URL と画像の直接 URL を混同しないでください。私的情報は公開しません。

新着カルーセルまたは Koha リストを使えます。リスト番号は URL の `shelfnumber=` から指定します。題、件数、形、速さ、自動再生を調整し **Refresh carousel** で更新します。表紙が出なくても書誌が消えたとは限りません。外部表紙取得には通信が必要です。

OPAC の簡易ボタンと staff ホームのボタンは別です。文字、URL、開き先、順序を確認し、**Add a button** と行の削除を使ってから適用します。

## ログイン、ニュース、フッター

ログイン枠の画像・説明・HTML は安全でないスクリプト、スタイル、イベントを除去します。一般利用者に見せない内部手順は置かないでください。両画面のニュースは管理対象の個別項目として公開し、図書館が作った独立ニュースを置換しません。

フッターは `Field: value`、追加リンクは `Text|URL` 形式で最大六つです。公開してよい連絡先だけを入力します。

**Remove** は確認と backup の後に管理テーマを外し、独自カスタマイズを保つための操作です。全体 restore でも他の管理作業の取り消しでもありません。誤った画像や色だけならその項目を直して再適用し、失敗時のメッセージは調査用に残してください。
