# 5. Обогащение и Z39.50/SRU

[Содержание](README.md)

## Обогащение

Импорт переносит экспорт, обогащение дополняет или находит новую книгу. Совпавшее название требует библиографической проверки. **Library tools > On-demand enrichment**, `n`; старый пакетный экран не текущий путь меню.

`all` или `biblionumbers`, например `101, 102, 500-510`, **Search**. Наблюдайте задачу/серверы; большие в фоне могут продолжить после перезагрузки при доступной машине. **Pause/Resume** не отменяет внесённое. Отчёт: темы/классы/примечания/физическое описание. **Search more servers** новые источники, **Choose donor** донор групп полей. **Apply** после просмотра/согласия; поиск/отчёт не пишут.

Прямой Z39.50 имеет лимиты/сбои, отсутствие результата не доказывает отсутствия книги. Нет общего лимита 50 записей: порог защиты применения, копии записей для малого, проверенный полный backup для большого. **Revert** возвращает версии по защитам, сохраняет позже правленные, не глобальный restore/отмена всех чужих правок.

## Новое и авторитетные

ISBN/название с автором/годом, **Find**, проверить/выбрать. **Import as new record** добавляет с подтверждением без замены того же ISBN. Удаляет местные `9XX` донора, отмечает источник, чтобы чужие экземпляры не стали вашими. Проверьте запись и создайте местные единицы обычно; партия через **Undo a MARC import**.

**Enrich & standardize authorities**, `h`: охват, точные/близкие формы. Близкие могут предлагать исправление/предварительные авторитетные записи: особо проверить. Сначала собственные Koha, затем база обогащения/прямые серверы; бразильские приоритетны и темы только оттуда. Не гарантия местной политики. **Apply** создаёт нужные записи/связи с backup, сохраняет изменения после отчёта. Revert оставляет созданные авторитетные записи, пока связаны.

## Серверы

**Z39.50 / SRU servers**, `z`: входящий позволяет чужой поиск и переключает порт firewall. Общая сеть отлична от прямых источников. **Reset/Reset all** разрешает повтор, не чинит удалённый сервер. Пробел выбирает, **Scan** ищет настоящую запись, **Add to Koha** добавляет выбранные рабочие. SRU в настройке не означает каждый запрос SRU; выходящий поиск не требует открывать вход.

**Требует подтверждения:** доступность/покрытие/условия внешнего источника из местной сети в момент использования.
