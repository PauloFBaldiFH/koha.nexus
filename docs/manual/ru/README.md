# Руководство пользователя Koha.Nexus

Руководство описывает установщик и панель Koha.Nexus, не заменяя полную документацию Koha по каталогизации и выдаче. Текст написан вручную на основе португальского/английского и проверен по коду `d81eb64`. Чтение кода не является испытанием установки на настоящем оборудовании.

Названия действий оставлены английскими для точного соответствия ключам кода; панель может показывать перевод. Команды и пути не переводятся. Разрушительные операции могут заменить/удалить данные: читайте согласие. «Требует подтверждения» обозначает то, чего один код не гарантирует. Не используйте старые номера меню.

## Требует подтверждения

- Публичная доступность и URL Microsoft Store.
- Официальный минимум RAM Linux, не требуемый численно проверкой.
- Полная работа MSIX на ARM64; манифест x64.
- Закрытые структуры/версии экспорта без образца и проверки.
- Доступность и условия внешних источников из местной сети.
- RAM, диск и время ИИ по оборудованию/выбору.
- Домен, сеть и правила публикации учреждения.
- Причины сбоев без полного сообщения и журнала.
