# 3. Backup и restore

[Содержание](README.md)

## Центр и виды копий

**Backup center**, `b`: дата, размер, результат, **Compression** и карточки.

| Карточка | Назначение |
| --- | --- |
| Download latest backup | Скопировать новейший найденный файл |
| Generate manual backup and download to PC | Создать, проверить и перенести базу |
| Export MARC21 records now | Библиография и авторитетные записи |
| Restore database | Заменить текущую базу |
| Configure cloud backup | Внешняя отправка |
| Test integrity of latest backup | Пробный временный импорт |

**Restore database является карточкой**, не верхней кнопкой или отдельным главным пунктом. Итог относится к ночной задаче, дата/размер к новейшему файлу, возможно иной операции.

SQL содержит базу Koha, не полный образ Windows/Debian. MARC21 включает библиографию/авторитетные записи в `.tar.gz`, не заменяет SQL для читателей/выдачи. Перед restore базы с таблицами создаётся проверенная защитная копия; пустая может пропустить её.

Автоматический SQL/защитные копии `/var/backups/koha_sql`, MARC `/var/backups/koha_marc`. Ручной backup имеет отдельное место, обычно `backups` в определённой домашней папке. `.part` остаётся временным до проверок/переименования.

## Сжатие и перенос

**Compression**: gzip `.sql.gz` совместимый, Zstandard `.sql.zst` быстрый/меньший для больших каталогов, XZ/LZMA `.sql.xz` минимальный/медленнее. Выбор сохраняется сразу без другой кнопки, для новых ночных/ручных/защитных, без пересжатия старых. Нет программы/сбой установки: читайте реальный формат, возможен gzip. Restore независимо узнаёт `.sql/.sql.gz/.sql.zst/.sql.xz`; расширение не доказывает содержимое.

**Generate manual backup and download to PC**: проверьте доступную для записи папку сервера, **Save backup**, ждите создание/проверку. Во время записи/копирования экран не закрывается. Имя/размер/путь проверить. WSL **Save to Windows Downloads/Choose folder in Windows**; удалённо показанную команду выполните у себя. Проверьте получение, **Finish and exit**.

Windows-кнопки только WSL; чужие команды не копируйте, зависят от файла/сервера. При другом backup/restore ждите, не обходите общую блокировку внешними параллельными задачами. **Download latest backup** берёт существующий файл, не создаёт. Desktop-Linux/WSL пробует Downloads, SSH может показать местную команду. Нет файла: создайте вручную.

## Проверка, MARC, облако

**Test integrity of latest backup**: дата/файл, **Choose another file**, согласие и временный импорт. Успех сообщает таблицы/записи/читателей без замены рабочего каталога. Относится к этой копии/среде; сохраните доступ к той же переданной копии.

**Export MARC21 records now** подтвердите, дождитесь пакета библиографии/авторитетных записей, проверьте путь/содержимое/перенос. Koha продолжает работать; настроенное облако сообщает отправку. SQL сохраняйте для всей базы.

**Configure cloud backup**: два пути Google Drive и в том числе OneDrive/MEGA/S3. Авторизация на сервере/другом компьютере, только показанные URL/инструкции. S3 различает сервис, регион/endpoint, bucket. Дождитесь реальной пробной отправки и получения; ошибочная настройка ненадёжна. Частные данные только в установке, не публичные тексты/изображения/поддержка; файлы их хранения здесь не указаны. SQL ежедневно 23:00, MARC воскресенье 03:00 по серверу по умолчанию, cron может отличаться.

## Разрушительный restore

**Подтверждение разрешает замену текущей базы.** Запланируйте обслуживание и внешнюю копию: панель не выполняет эту дополнительную рекомендацию за вас.

**Restore database**: доступный серверу файл с переносом при необходимости. WSL может скопировать Windows-файл в Linux. Читайте доступность/содержимое/целостность/место, выясняйте подозрительный/неполный файл. Ещё раз проверьте при согласии: до него можно отказаться, после ждать без закрытия, отмены нет.

Сначала временный SQL-импорт, проверка основных таблиц/числа. Сбой останавливает до замены. Существующим таблицам проверенная копия SQL `pre_restore_safety_backup_` с датой/временем/сжатием; ошибка копии не должна удалить текущую базу. Пустая может пропустить.

Далее остановка клиентов, создание/импорт, обновление схемы, синхронизация поиска, индексы, службы. Сохранённая тема повторно применяется по возможности. Ошибка теста/копии не означает замены. На создании/импорте/схеме возможен возврат по этапу/копии, **но rollback тоже может не сработать**. Индекс может дать ошибку после restore базы, не вернув старый каталог.

Сохраните полное сообщение, `/var/log/koha-easy-install/restore.log`, `/var/log/koha-easy-install/restore-import.log`, для индекса `/var/log/koha-easy-install/zebra-rebuild.log`. Используйте карточку центра, не старые номера; техническая помощь при неопределённости. Проверьте dashboard/записи/поиск OPAC/staff. Завершение SQL не подтверждает внешние файлы.
