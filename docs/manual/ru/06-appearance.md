# 6. Оформление OPAC и staff

[Содержание](README.md)

**OPAC and Staff Appearance**, `o`, отдельно настраивает публичный OPAC и staff/интранет.

**Sync current OPAC settings** читает без применения. Меняйте по группе. **Preview** показывает CSS/JavaScript/содержимое, не полноценную страницу. **Apply** итог/подтверждение и предварительный backup. В браузере проверьте начало/поиск/запись/вход и малый экран.

Блоки в `OpacUserCSS/OpacUserJS`, при нужде `IntranetUserCSS/IntranetUserJS`; собственные сохранены, визуальные конфликты с другими настройками возможны.

## Параметры и материалы

Текстура/размытие/непрозрачность/углы/цвета/фон, светлая/тёмная и начальная тема: сохраняйте контраст при изображении/прозрачности. Staff: верхняя панель/быстрый поиск/модули/плотность таблиц/текст/контраст. **Apply color theme to Staff Client** включить; **Copy OPAC preset** лишь заполняет, **Apply** пишет.

Доступный серверу файл, предложенный сервис или прямая HTTPS-URL. PNG/JPEG/GIF/WebP/ICO принимаются, SVG отвергается. Только клиентский файл сделайте доступным серверу. Права на изображение/доступное описание входа; хостинговая страница не всегда адрес картинки. Настройте внешние сервисы без публичных частных сведений.

Карусель новинок/списка Koha с `shelfnumber=`; название/число/стиль/скорость/autoplay/**Refresh carousel**. Нет обложки не значит удалена запись: доступность данных/обложек/сети. Кнопки OPAC/staff отдельно, текст/адрес/цель/порядок, **Add a button**, удаление строки до применения.

Вход: изображение/описание/HTML без скриптов/стилей/событий, не секретные инструкции. Новости каждой стороны собственные название/текст/кнопки, библиотечные не заменяет. Подвал `Field: value`, дополнительные ссылки текст `|` адрес, максимум шесть, публичное.

**Remove** подтверждает и делает backup до удаления блоков темы, возвращая Koha-вид с собственными настройками. Не полный restore/отмена другого управления. Исправьте нужную группу и примените; ошибку сохраните для диагностики.
