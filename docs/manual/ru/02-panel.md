# 2. Начало работы и панель

[Содержание](README.md)

## Открытие и навигация

В подготовленной Debian/Ubuntu:

```bash
sudo config.sh
```

Windows: значок **Koha** или MSIX. Первый запуск может спросить язык. При ошибке подготовки Textual возможна классическая панель. Здесь описан главным образом Textual, не старая нумерация меню.

Стрелками выделите раздел, **Enter** либо щелчок открывает. Выделение само ничего не запускает. Откройте карточку задачи, прочитайте вопросы. **Tab** меняет фокус; выйдите из текстового поля перед буквенными сочетаниями.

| Клавиша | Действие |
| --- | --- |
| `d` | Control Dashboard |
| `b` | Backup center |
| `c` | Терминал Debian |
| `Ctrl+B` | Показать/скрыть боковую панель |
| `q` | Выйти из панели |

Выход из простаивающей панели не выключает сервер. Во время работы соблюдайте её правила отмены. Установка/restore имеют неотменяемые этапы; принудительно закрывать небезопасно.

## Состояние и адреса

Dashboard показывает Koha/доступную память, последний backup с датой/возрастом/файлом, свободный диск, адреса, MariaDB, Apache, RabbitMQ, Memcached, Koha и HTTP-проверки. Backup учитывает возраст и последний ночной итог: свежий файл возможен при ночном сбое. Читайте оба; хороший индикатор не заменяет restore-тест. HTTP не доказывает завершённый веб-установщик или все библиотечные функции.

**Refresh** перечитывает; **Restart Koha** запрашивает ремонт/перезапуск с учётом пользователей; **Export diagnostics** готовит поддержку. Кнопки могут быть недоступны, если установленный установщик не поддерживает задачу.

Адресные карточки открывают/копируют URL; без запуска браузера вставьте на своём компьютере. На сервере OPAC `http://localhost/`, staff `http://localhost:8080/`, порты 80/8080. На другом компьютере нужен сетевой адрес, не его `localhost`. При WSL NAT/недоступном LAN проверьте Windows-сеть с ответственным, не предполагая доступ отовсюду.

Завершите веб-установщик Koha, если он появился; экраны зависят от версии. **Create super librarian** в **Koha settings & parameters** создаёт запись, частные значения только там.

Перед работой обновите dashboard, проверьте компоненты/адреса, откройте OPAC/staff правильно, создайте/проверьте backup и внешнюю копию с ответственным за возврат. Последнее является эксплуатационной рекомендацией: нужен завершённый проверенный перенос.
