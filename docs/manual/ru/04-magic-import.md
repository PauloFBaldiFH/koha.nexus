# 4. Магический импорт

[Содержание](README.md)

## Подготовка и форматы

Magic Import читает библиографию, экземпляры, читателей и авторитетные записи. Узнанный формат не гарантирует поля, особенно без заголовков/локальные. Сохраните оригинал/проверенный backup, представительную выборку с несколькими экземплярами, диакритикой, пустыми значениями/исключениями, сравните числа источника. Экспорты читателей не публикуйте.

**Magic Import Tool**, `i`, карточка и файл/папка доступны Linux панели; файл лишь на компьютере браузера/терминала не попадает автоматически на сервер.

| Вход | Проверка |
| --- | --- |
| MARC21 ISO 2709, MARCXML, MARC-текст | Названия/символы/авторитетные/экземпляры; MarcEdit `.mrk` узнаётся без конверсии только из-за расширения. |
| CSV/TSV, `.xlsx/.xls/.ods/.dbf` | Разделитель/заголовки/значения/назначения. |
| Табличный JSON/XML | Структура; произвольный XML не обязательно MARCXML. |
| Табличный SQL без заголовков допустим | Чтение данных/связей, не исполнение миграционной программы; проверить неоднозначность. |
| ISIS | Узнанный PostgreSQL с `acervo`; основной CDS/ISIS `.mst` экспортировать WinISIS ISO 2709. |
| Biblioteca Fácil | Узнанный backup/папка, связанные таблицы вместе, отдельно записи/читатели/выдачи/заказы. |
| Полный backup Koha | К restore, не добавлению записей. |

Чужой PostgreSQL, особенно бинарный `pg_dump`, не готовая MariaDB. При отказе экспортируйте MARC/таблицы в источнике. Каждый член архива проверить. PDF/картинки/документы/программы не библиографический экспорт этого средства.

## Сопоставление

Проверьте **Bibliographic/Patrons/Authorities**. Сетка/назначения, высота разделителем либо **Ctrl+Up/Down**. Оставить/перенаправить/фиксированный текст/пропустить; понять связи перед удалением ID. **Values of this Koha**: коды, библиотека/тип/категория по умолчанию, замены источник/цель. **Record preview** результат; **Check the whole file** вся подготовка/проверка без импорта. Профиль имя/**Save**, выбор/**Use**, при изменении структуры пересмотреть. **Apply/Ctrl+S** принимает сопоставление, не финальную запись. **Skip: import as it is/Esc** пропускает сопоставление, не отменяет всё. Группировку/правку текста предварительно просмотреть, не менять слепо сокращения/имена/коды.

## Данные

`952` сохраняются, библиотека/тип по запросу переназначаются; действующий иной код не заменять лишь ради стандарта. Barcode, домашняя/текущая библиотека, шифр, тип, местоположение, поступление. Локальные `949/852/950/990` у Pergamum/Biblivre могут значить разное. Пометка обязательного экземпляра `DL`/дата не создаёт автоматически местную единицу: проверить исключения и независимые инвентарные признаки. Нет barcode: обычно проверка; генерация требует выбора/стабильной идентичности миграции/источника, без скрытого перенумерования коллизий. SQL-связь должна распознаться, не угадываться из позиции/порядка; исправить до импорта.

**Patrons**: имя/фамилия/билет/контакт/адрес/даты/библиотека/существующая категория. E-mail/CPF/дата лишь признаки, рождение/запись/истечение похожи. Обновление существующих спрашивается с сопоставлением билета, не только новые. Права/аутентификацию не угадывать. **Authorities**: ID, утверждённая форма, варианты, связи, тип; смена режима не создаёт отсутствующих сведений.

Читайте числа/отказы/вопросы. Существующее оставить с новыми экземплярами, заменить либо создать без сравнения. **Поздняя ошибка может оставить ранние этапы импортированными.** Сохраните итог/журналы, проверьте завершённые этапы/выборку/единицы/людей/связи до повтора. **Library tools > Undo a MARC import** для MARC, не всех читателей/выдач/заказов. Вся база по правилам Backup center.

**Требует подтверждения:** конкретная закрытая структура/версия экспорта без образца и проверки.
