# 1. Установка

[Содержание](README.md)

## Среда и требования

В Windows Koha работает внутри Debian через WSL 2. Средства Windows подготавливают среду, открывают панель и интегрируют приложение. В Debian/Ubuntu службы и панель устанавливаются напрямую. Готовый каталог открывайте через панель, а не повторной установкой.

| Среда | Проверки в коде |
| --- | --- |
| Windows | Windows 10 версии 2004, сборка 19041 или новее, либо Windows 11; 64 бита, включённая виртуализация; RAM 8 GB, желательно 12 GB; свободно 10 GB на установочном диске, желательно 20 GB. |
| Debian/Ubuntu | Debian 11/12/13 или Ubuntu 22.04/24.04; указаны amd64/arm64; менее 5 GB блокирует, от 5 до менее 10 GB предупреждает, от 10 GB проверка пройдена. |

Каталог, вложения, индексы и backup требуют дополнительного места. **RAM Linux требует подтверждения:** руководство рекомендует выделенному серверу 4 GB, лучше 8 GB; рабочему столу/виртуализации 8 GB, лучше 12 GB. Текущая проверка Linux не требует числового минимума RAM. Успех не гарантирует любую нагрузку. Windows учитывает аппаратно зарезервированную память: определяемые пороги 7,5 и 11,5 GB.

Linux требует административных прав и доступа к репозиторию пакетов Koha. TCP 80/8080 используются OPAC/staff. Если заняты, предлагается остановить соответствующие службы. **Соглашайтесь только при допустимости их прерывания.**

## Windows: PowerShell

Войдите в административную учётную запись Windows, которая будет использовать Koha. Откройте PowerShell от администратора в той же записи:

```powershell
irm https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/main/windows/install.ps1 | iex
```

Если повышение прав требует чужую запись, отмените и войдите правильно: WSL принадлежит установочной записи. Прочитайте проверки, устраните отключённую виртуализацию. Ответьте в окне на вопросы об учётной записи Debian, отдельной от библиотечной Koha.

Дождитесь WSL 2/Debian. Запрошенная перезагрузка регистрирует продолжение при следующем входе Windows. Выберите язык/**Install Koha server**. После установки в панели выйдите штатно и дождитесь интеграции Windows.

Обычно `C:\Koha`, старая установка может сохранить `C:\KohaEasy`. Не переносите папку для ремонта прерывания. Сохраните ошибку: завершённые этапы записываются, повторный запуск может продолжить или открыть панель для завершения. Это не делает разрушительную переустановку безопасной.

## MSIX

Пакет готовит ту же WSL; его установка не завершает сервер/базу. Используйте **обычный PowerShell без предварительного повышения прав**:

```powershell
irm https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/main/windows/msix/instalar_msix.ps1 | iex
```

Помощник загружает заданный кодом пакет, проверяет происхождение, запрашивает административное разрешение и устанавливает текущему пользователю. Не игнорируйте отказ. Дождитесь подготовки, завершите установку сервера, штатно выйдите из панели и дождитесь ярлыков, задач и сети Windows. Раннее закрытие не завершает Koha: откройте снова.

**Требует подтверждения:** публичная доступность/адрес Microsoft Store; упаковочный код не доказывает публикацию. Полная работа MSIX на ARM64 также не подтверждена: манифест x64, Linux-arm64 не доказательство. Манифест допускает более старую Windows, чем весь процесс WSL; планируйте по полным требованиям выше.

## Debian/Ubuntu

В терминале сервера:

```bash
wget https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/refs/heads/main/installer
sudo bash installer
```

С локальным репозиторием и переводами:

```bash
git clone https://github.com/PauloFBaldiFH/koha.nexus.git
cd koha.nexus
sudo bash installer
```

Язык/**Install Koha server**. Критические ошибки сначала исправьте; предупреждение не гарантирует производительность. WSL нужен версии 2 с работающим systemd; WSL 1 отклоняется. В Windows предпочтительна описанная подготовка с подсказками.

## Установка в панели

Откройте **Install Koha server**, дождитесь проверки/отчёта, оцените последствия освобождения портов. Подтвердите целевой компьютер, часовой пояс либо регион/город. **Есть экземпляр Koha: остановитесь и проверьте.** Переустановка удаляет базу/конфигурацию, требует дополнительного согласия и точно `REINSTALL`. Не используйте лишь для открытия/обновления панели.

Не закрывайте: отмены нет. Оценка 10–30 минут зависит от оборудования/сети. Прочитайте итог/отчёт: завершение с проблемами не означает исправные службы. Оцените перезагрузку и в MSIX дождитесь продолжения Windows. Частные данные результата не публикуйте в документах или обращениях.
