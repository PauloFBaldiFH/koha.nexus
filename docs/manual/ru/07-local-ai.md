# 7. Локальный ИИ

[Содержание](README.md)

**AI**, `a`: поставщик, Ollama, фотокаталогизация MARC Replace и staff-ассистент. Настройка поставщика не устанавливает инструменты.

## Локальная настройка

Предупреждение CPU/RAM: Koha может замедлиться. **Ollama on this server > Check Ollama**, при отсутствии **Install Ollama**. Выбор/**Download** требует сеть/диск; названия моделей не фиксируем, список меняется. **Local Ollama**, URL (обычно `http://127.0.0.1:11434`), **Use for chat/Use for cataloguing**. Фото нужно зрение, текста недостаточно. **Test connection/Save**, **F5/Ctrl+S**; заполнение не сохраняет. Пустой чат использует выбор зрения. **Load models** запрашивает поставщика, встроенный резервный список обозначается.

Установленное занимает диск, загруженное RAM. **Free memory** выгружает без удаления, затем может загрузить. Ollama видна и с другим поставщиком: проверьте сохранённые URL/поставщика, установка не доказывает локальную обработку.

## Инструменты

MARC Replace установить/обновить, проверка компиляции/ярлыков staff. Одна запись: `.mrc/.xml` или текст, `biblionumber`, **Preview**, сравнить/подтвердить. Пусто создаёт новую, избегайте дубля. Экземпляры остаются, входящие поля единиц исключены. Прошлый MARCXML можно скачать/послать тому же ID для возврата, не замена полного backup.

**AI cataloguing**: читаемые обложка/титул/оборот, JPEG/PNG/WebP, минимум одна. Framework/целевая запись, **Read the photos**, дождаться и сравнить название/ответственность/выходные данные/ISBN/класс/пропуски. Исправьте MARC до записи, классификацию проверьте по таблицам; цифра ISBN не доказывает издание. Черновик не пишет поля экземпляров.

**Install, update or remove the assistant** заменяет новости начала staff, не OPAC. Поиск Koha/заданные чтения, не произвольный SQL. **Предложение не исполнено:** запись/до-после/эффект, **Approve & Execute** с собственными правами. Промежуточная правка может отклонить/запросить новое. Подтверждённые действия просматриваются; удалить разговор/ассистента не значит отменить. Удаление стирает разговоры, сохраняет историю согласованных изменений.

Наблюдайте оборудование/Koha, при медленной работе не запускайте новые фото, освобождайте память уместно. Нет гарантии времени. Внешний поставщик получает запрос: политика данных/изображений, не тестировать настоящими читателями. Ценовая метка не обещает бесплатность.

**Требует подтверждения:** RAM/диск/задержка по выбору/оборудованию; минимум Koha не гарантирует ИИ.
