# Podręcznik użytkownika Koha.Nexus

Podręcznik opisuje instalator i panel Koha.Nexus, nie zastępuje pełnej dokumentacji Koha o katalogowaniu i wypożyczeniach. Tekst napisany ręcznie na podstawie portugalskiego/angielskiego i sprawdzony z kodem `d81eb64`. Przegląd kodu nie jest testem instalacji na rzeczywistym sprzęcie.

Nazwy działań pozostają angielskie dla dokładnej identyfikacji kluczy kodu; panel może je tłumaczyć. Polecenia i ścieżki nie są tłumaczone. Działania destrukcyjne mogą zastąpić/usunąć dane: czytaj potwierdzenie. „Do potwierdzenia” oznacza niepewność, której sam kod nie rozstrzyga. Nie używaj starych numerów menu.

## Do potwierdzenia

- Publiczna dostępność i URL Microsoft Store.
- Oficjalne minimum RAM Linux, niewymuszane liczbowo w preflight.
- Pełna praca MSIX na ARM64; manifest x64.
- Własnościowe układy/wersje eksportu bez próbki i przeglądu.
- Dostępność i warunki źródeł zewnętrznych z lokalnej sieci.
- RAM, dysk i czas AI według sprzętu/wyboru.
- Domena, sieć i instytucjonalna polityka publikacji.
- Przyczyny błędów bez pełnego komunikatu i logu.
