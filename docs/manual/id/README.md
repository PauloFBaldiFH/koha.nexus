# Panduan pengguna Koha.Nexus

Panduan sembilan bab ini menjelaskan instalasi dan panel Koha.Nexus, bukan pengganti panduan lengkap katalogisasi dan sirkulasi Koha. Teks ditulis secara manual dari bahasa Portugis dan Inggris serta diperiksa terhadap kode 8c2633d. Pemeriksaan kode bukan pengujian instalasi nyata. Nama tindakan tetap dalam bahasa Inggris agar sesuai dengan kode; panel dapat menampilkannya dalam terjemahan. Perintah dan jalur tidak diterjemahkan. Baca konfirmasi tindakan yang mengganti atau menghapus data. Jangan mengandalkan nomor menu lama.

## Perlu dikonfirmasi

- Ketersediaan publik dan URL Microsoft Store.
- Minimum RAM Linux resmi, yang tidak dipaksakan secara numerik oleh pemeriksaan awal.
- Fungsi MSIX lengkap pada ARM64; manifest masih x64.
- Tata letak dan versi ekspor khusus tanpa sampel dan pemeriksaan hasil.
- Ketersediaan serta syarat sumber eksternal dari jaringan lokal.
- RAM, disk dan waktu respons AI menurut perangkat keras dan pilihan.
- Domain, jaringan dan kebijakan publikasi lembaga.
- Penyebab kegagalan tertentu tanpa pesan lengkap dan log.
