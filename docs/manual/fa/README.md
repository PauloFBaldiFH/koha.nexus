# راهنمای کاربر Koha.Nexus

این راهنمای نه‌فصلی نصب و پنل Koha.Nexus را توضیح می‌دهد و جایگزین راهنمای کامل فهرست‌نویسی و امانت Koha نیست. متن به صورت دستی با استفاده از منابع پرتغالی و انگلیسی نوشته و با کد 8c2633d مقایسه شده است. بررسی کد، آزمون نصب واقعی نیست. نام اقدامات برای تطبیق دقیق با کد به انگلیسی حفظ شده‌اند؛ پنل ممکن است آنها را ترجمه کند. دستورها و مسیرها ترجمه نمی‌شوند. پیش از حذف یا جایگزینی داده، تأییدیه را بخوانید و به شماره‌های قدیمی منو تکیه نکنید.

## نیازمند تأیید

- دسترسی عمومی و URL در Microsoft Store.
- حداقل رسمی RAM در Linux که بررسی اولیه آن را به صورت شرط عددی اعمال نمی‌کند.
- عملکرد کامل MSIX روی ARM64؛ manifest فعلی x64 است.
- ساختار و نسخهٔ خروجی اختصاصی بدون نمونه و بازبینی نتیجه.
- دسترسی و شرایط منابع بیرونی از شبکهٔ محلی.
- RAM، دیسک و زمان پاسخ هوش مصنوعی بر اساس سخت‌افزار و انتخاب.
- دامنه، شبکه و سیاست انتشار سازمان.
- علت شکست مشخص بدون پیام و گزارش کامل.
