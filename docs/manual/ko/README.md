# Koha.Nexus 사용자 안내서

이 안내서는 Koha.Nexus 설치 프로그램과 패널을 설명하는 아홉 장으로 구성됩니다. Koha 자체의 전체 목록·대출·도서관 운영 안내를 대신하지 않습니다. 포르투갈어와 영어 자료를 바탕으로 직접 작성하고 `48aa634`의 소스와 대조했습니다. 소스 검토는 실제 컴퓨터에서 설치를 시험했다는 뜻이 아닙니다.

작업 이름은 코드와 정확히 맞추기 위해 영어로 남겼으며 설치된 패널에서는 번역되어 보일 수 있습니다. 명령과 경로는 번역하지 않습니다. 데이터를 교체하거나 삭제하는 작업의 확인문을 읽으십시오. 이전 메뉴 번호를 현재 화면의 위치로 사용하지 마십시오. 코드만으로 확정할 수 없는 항목은 아래에 따로 표시했습니다.

이 문서는 `docs/manual/`의 전체 사용자 안내서입니다. 대화형 미리보기의 `preview/manual/`에 있는 카드별 짧은 도움말은 별도 자료이며 이 번역에서 변경하지 않았습니다.

## 확인이 필요한 사항

- Microsoft Store의 일반 공개 여부와 URL.
- 현재 사전 검사에서 숫자 조건으로 강제하지 않는 Linux의 공식 최소 RAM.
- ARM64에서 MSIX 전체 과정의 작동 여부. 생성 manifest는 x64입니다.
- 표본과 결과 검토가 없는 독자적인 내보내기 구조·제품 버전의 호환성.
- 도서관 네트워크에서 외부 출처의 가용성과 접속 조건.
- 장비와 선택에 따른 AI의 RAM·디스크 요구량과 응답 시간.
- 서비스 공개에 필요한 도메인·네트워크와 기관 정책.
- 전체 메시지와 로그가 없는 구체적인 실패의 원인.
