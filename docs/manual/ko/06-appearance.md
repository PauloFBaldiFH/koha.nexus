# 6. OPAC과 staff의 화면 구성

[목차](README.md)

## 작은 변경부터 적용

사이드바의 **OPAC and Staff Appearance** 또는 o로 여십시오. 공개 OPAC과 직원용 staff는 각각 설정을 가집니다. 먼저 **Sync current OPAC settings**로 현재 값을 읽습니다. 동기화는 새 테마를 적용하는 동작이 아닙니다.

한 번에 한 묶음만 조정하고 색, 글자 가독성, 그림을 확인하십시오. **Preview**는 Koha에 쓸 CSS, JavaScript, 내용을 보여주며 완전한 브라우저 화면이 아닙니다. **Apply**는 데이터베이스 backup 후 요약과 확인을 거쳐 저장합니다. 이어 브라우저에서 양쪽 홈, 검색, 레코드, 로그인과 작은 화면을 시험합니다.

패널은 OPAC의 `OpacUserCSS`와 `OpacUserJS`, staff의 `IntranetUserCSS` 및 필요한 `IntranetUserJS`에 관리 블록을 기록합니다. 도서관의 독자적인 블록은 보존하지만 외부 맞춤 코드와의 시각적 충돌이 없다는 보장은 아닙니다.

질감, 흐림, 불투명도, 모서리, 강조색과 배경을 조절할 때 충분한 대비를 유지하십시오. 밝음·어두움 전환과 기본 테마는 구분된 설정입니다. staff는 색, 상단 바, 빠른 검색, 모듈 카드, 표 밀도, 글자 크기와 대비를 따로 설정합니다. **Apply color theme to Staff Client**를 활성화하고, **Copy OPAC preset**은 입력란만 채운다는 점을 기억하십시오. 실제 저장은 **Apply**입니다.

## 이미지와 이동 버튼

서버 파일, 화면에 나온 이미지 호스팅 서비스 또는 직접 HTTPS URL을 선택할 수 있습니다. PNG, JPEG, GIF, WebP, ICO를 허용하며 SVG는 거부합니다. 사서 컴퓨터의 파일은 먼저 서버에서 읽을 수 있어야 합니다. 사용 권한이 있는 이미지를 쓰고 로그인 화면에는 화면 읽기 프로그램용 설명을 제공하십시오. 호스팅 웹 페이지의 주소가 이미지 자체 주소인 것은 아닙니다. 비공개 정보를 공개 이미지나 로그인 화면에 넣지 마십시오.

회전 목록은 신착 자료나 Koha 목록을 표시합니다. 목록 번호는 주소의 `shelfnumber=`에서 확인합니다. 제목, 개수, 스타일, 속도, 자동 재생을 조정하고 **Refresh carousel**로 갱신합니다. 표지가 없다고 레코드가 사라진 것은 아니며 외부 표지에는 네트워크가 필요합니다.

OPAC 바로 가기와 staff 홈 버튼은 따로 구성합니다. 문구, URL, 열기 대상, 순서를 확인합니다. **Add a button**으로 행을 추가하거나 행의 제거 버튼을 누른 다음 적용하십시오.

## 로그인, 소식, 바닥글

로그인 상자에는 이미지, 설명, HTML을 넣을 수 있으며 스크립트, 스타일, 이벤트 처리기 같은 위험 요소는 걸러집니다. 방문객이 보아서는 안 되는 내부 지침을 게시하지 마십시오.

OPAC과 staff의 소식은 각각 제목, 내용, 버튼을 가지며 패널 관리 항목으로 발행됩니다. 이 방식은 도서관이 독립적으로 만든 기존 소식을 교체하지 않습니다. 바닥글은 `Field: value` 줄 형식을 사용하고, 추가 링크는 `Text|URL`처럼 구분자 `|`를 넣어 최대 여섯 개까지 입력합니다. 공개 가능한 정보만 작성하십시오.

## 테마 제거

**Remove**는 확인과 backup 후 패널의 테마 블록을 제거하고 도서관 고유의 맞춤 부분을 보존하는 작업입니다. 전체 데이터베이스 restore나 다른 관리 작업의 취소가 아닙니다. 그림 하나나 색 하나가 잘못되었다면 해당 묶음을 수정해 다시 적용하십시오. 실패하면 전체 오류를 보관하고 9장에 따라 조사합니다.
