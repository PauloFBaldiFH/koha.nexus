# 5. 레코드 보강과 Z39.50/SRU

[목차](README.md)

## 기존 레코드 보강

가져오기는 내보낸 자료를 받는 것이고, 보강은 기존 레코드의 추가 정보를 찾거나 새로 넣을 책을 찾는 작업입니다. 같은 제목이라는 사실만으로 서지 검토가 필요 없어지지는 않습니다.

**Library tools > On-demand enrichment** 또는 n으로 여십시오. 이전 일괄 보강 화면은 현재 메뉴의 경로가 아닙니다. 전체는 `all`, 일부는 `101, 102, 500-510` 같은 `biblionumbers`를 입력한 뒤 **Search**를 사용합니다.

작업과 서버 표를 관찰하십시오. 큰 작업은 백그라운드에서 실행되고 재시작 후 계속할 수 있지만, 진행하려면 컴퓨터가 가용 상태여야 합니다. **Pause**와 **Resume**은 검색을 제어하며 이미 적용한 변경을 취소하지 않습니다.

보고서를 열어 제안된 주제, 분류, 주기, 형태사항을 현재 레코드와 비교합니다. **Search more servers**는 아직 사용하지 않은 출처를 묻고, **Choose donor**는 필드 묶음의 출처를 선택합니다. 검토 후 **Apply** 확인을 읽으십시오. 검색과 보고서 작성만으로 제안이 목록에 저장되지는 않습니다.

현재 화면은 직접 Z39.50 연결을 사용합니다. 서버별 제한과 일시 중단이 있어 지연이나 결과 없음이 다른 목록에도 책이 없다는 증거는 아닙니다. 일반적인 50건 검색 제한은 없습니다. 적용 때 작은 작업은 레코드 사본, 큰 작업은 검증된 전체 backup으로 보호하지만, 검토를 생략할 수 있는 것은 아닙니다.

**Revert**는 해당 작업의 보호 규칙에 따라 이전 버전을 복구하고 적용 후 Koha에서 편집한 레코드는 보존합니다. 전체 데이터베이스 restore나 다른 사람의 모든 편집을 취소하는 도구가 아닙니다.

## 새 책 찾기와 등록

같은 화면에서 ISBN 또는 제목을 입력하고 저자·연도로 식별을 돕습니다. **Find** 후 출처를 살펴 결과를 고르고 **Import as new record**를 확인합니다. 이는 신규 등록이며 같은 ISBN의 기존 레코드를 교체하지 않습니다.

상대 목록의 로컬 `9XX` 필드를 제거하고 출처를 기록해 다른 도서관의 소장자료를 자관 자료로 가져오지 않게 합니다. 추가된 서지를 확인하고 자관 절차로 실제 소장자료를 만드십시오. 관련 MARC 묶음은 **Undo a MARC import**에서 처리할 수 있습니다.

## 전거 보강과 표준화

**Library tools > Enrich & standardize authorities** 또는 h에서 범위와 정확한 형태·유사 형태를 고릅니다. 유사 형태는 철자 수정과 잠정 전거를 제안할 수 있으므로 주의 깊게 검토하십시오.

먼저 이 Koha의 전거, 다음으로 보강 데이터베이스와 직접 서버를 검색합니다. 브라질 출처를 우선하며 주제 검색은 브라질 출처로 제한합니다. 이 정책이 모든 도서관의 목록 규칙에 맞는다는 보장은 없습니다.

보고서를 읽고 **Apply**하십시오. 안전 backup과 함께 필요한 전거를 만들고 서지에 연결합니다. 보고서 준비 후 편집된 레코드를 보존하며, 되돌릴 때도 연결이 남은 새 전거는 유지합니다. 무조건 삭제될 것이라고 기대하지 마십시오.

## Z39.50과 SRU 설정

사이드바 또는 z로 **Z39.50 / SRU servers**를 엽니다. 이 Koha의 서버는 다른 도서관이 자관 목록을 검색하도록 하며, 활성화·해제는 관련 방화벽 포트 개방도 바꿉니다. 공동 네트워크의 공유 출처 설정과 보강용 직접 서버는 다릅니다.

상태 표의 **Reset** 또는 **Reset all**은 재시도를 허용할 뿐 외부 서비스를 수리하지 않습니다. 출처는 Space로 선택하고 **Scan**으로 실제 검색한 뒤 작동하는 항목을 **Add to Koha**로 등록합니다. 단순한 포트 접속 확인이 아닙니다.

이 설정에 SRU가 있다고 모든 보강 검색이 SRU를 쓰는 것은 아닙니다. 외부를 검색하려고 자관의 수신 서버를 공개할 필요도 없습니다. **확인 필요:** 각 출처의 이용 시점 가용성, 범위, 조건과 자관 네트워크의 접근성은 서버 목록이나 소스만으로 확정되지 않습니다.
