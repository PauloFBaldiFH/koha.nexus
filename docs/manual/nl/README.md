# Koha.Nexus gebruikershandleiding

Deze handleiding beschrijft installer en Koha.Nexus-paneel, niet de volledige Koha-catalogisering en uitleenadministratie. Met de hand geschreven vanuit Portugees/Engels en gecontroleerd tegen code `755c1d8`. Code lezen is geen installatietest op echte hardware.

Actienamen blijven Engels om exacte codesleutels herkenbaar te houden; uw paneel kan vertaalde namen tonen. Opdrachten en paden worden niet vertaald. Een destructieve actie kan gegevens vervangen/wissen: lees bevestiging. “Nog te bevestigen” duidt niet uitsluitend uit code gegarandeerde uitspraken aan. Gebruik geen oude menunummers.

## Nog te bevestigen

- Openbare Microsoft Store-beschikbaarheid en URL.
- Officieel Linux-RAM-minimum zonder numerieke eis in huidige voorcontrole.
- Volledige MSIX-werking op ARM64; manifest x64.
- Propriëtaire exportlayouts/-versies zonder voorbeeld en controle.
- Externe beschikbaarheid/toegangsvoorwaarden op lokaal netwerk.
- AI-RAM, schijf en antwoordtijd per hardware/keuze.
- Domein, netwerk en institutioneel publicatiebeleid.
- Concrete foutoorzaken zonder volledig bericht en log.
