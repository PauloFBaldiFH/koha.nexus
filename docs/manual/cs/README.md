# Uživatelská příručka Koha.Nexus

Příručka popisuje instalátor a panel Koha.Nexus, nenahrazuje kompletní dokumentaci Koha pro katalogizaci a výpůjčky. Ručně napsáno podle portugalštiny/angličtiny a ověřeno proti kódu `d81eb64`. Kontrola kódu není instalační test na skutečném hardwaru.

Názvy akcí zůstávají anglicky pro přesné klíče kódu; panel je může překládat. Příkazy a cesty se nepřekládají. Destruktivní úloha může nahradit/smazat data: čtěte potvrzení. „K potvrzení” označuje nejistoty, které kód sám nezaručuje. Nepoužívejte stará čísla menu.

## K potvrzení

- Veřejná dostupnost a URL Microsoft Store.
- Oficiální minimum RAM Linux, předkontrolou číselně nevynucené.
- Plná funkce MSIX na ARM64; manifest x64.
- Proprietární rozvržení/verze exportu bez vzorku a revize.
- Dostupnost a podmínky vnějších zdrojů z místní sítě.
- AI-RAM, disk a odezva podle hardwaru/volby.
- Doména, síť a institucionální pravidla publikace.
- Příčiny chyb bez celého sdělení a protokolu.
