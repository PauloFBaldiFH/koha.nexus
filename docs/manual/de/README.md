# Koha.Nexus Benutzerhandbuch

Dieses Handbuch beschreibt Installer und Koha.Nexus-Bedienoberfläche, ersetzt aber nicht das Koha-Handbuch zu Katalogisierung und Ausleihe. Von Hand aus Portugiesisch/Englisch erarbeitet und mit Code `755c1d8` abgeglichen. Codeprüfung ist kein Installationstest auf realer Hardware.

Aktionsnamen bleiben Englisch, damit die exakten Code-Schlüssel erkennbar sind; das eigene Panel kann übersetzte Namen zeigen. Befehle und Pfade werden nicht übersetzt. Destruktive Vorgänge können Daten ersetzen/löschen: Bestätigung lesen. „Noch zu bestätigen“ kennzeichnet nicht allein aus dem Code garantierte Aussagen. Keine alten Menünummern verwenden.

## Noch zu bestätigen

- Öffentliche Microsoft Store-Verfügbarkeit und URL.
- Offizielles Linux-RAM-Minimum ohne numerische Erzwingung im aktuellen Preflight.
- Durchgehende MSIX-Funktion auf ARM64; Manifest x64.
- Proprietäre Exportlayouts/-versionen ohne Stichprobe und Prüfung.
- Verfügbarkeit/Zugangsbedingungen externer Quellen im lokalen Netz.
- KI-RAM, Platte, Antwortzeiten je Hardware und Wahl.
- Domain, Netz und institutionelle Veröffentlichungsvorgaben.
- Konkrete Fehlerursachen ohne vollständige Meldung und Log.
