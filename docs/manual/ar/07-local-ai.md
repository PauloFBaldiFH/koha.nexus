# 7. الذكاء الاصطناعي المحلي

[المحتويات](README.md)

**AI** أو `a`: المزود وOllama وفهرسة صور MARC Replace ومساعد staff. الإعداد لا يثبت الأدوات تلقائياً.

اقرأ تحذير CPU/RAM، قد يبطؤ Koha. **Ollama on this server > Check Ollama** ثم **Install Ollama** إن غاب. اختيار و**Download** يحتاجان شبكة وقرصاً؛ أسماء النماذج ليست ثابتة لأن القائمة تتغير. **Local Ollama** وتحقق URL (عادة `http://127.0.0.1:11434`) و**Use for chat/Use for cataloguing**. الصور تحتاج قدرة بصرية لا نصاً فقط. **Test connection/Save** أو **F5/Ctrl+S**؛ الملء لا يحفظ. الدردشة الفارغة تستخدم اختيار الرؤية. **Load models** يسأل المزود ويبين القائمة الاحتياطية المدمجة.

المثبت يشغل قرصاً، والمحمّل RAM. **Free memory** يفرغ دون حذف ويمكن التحميل لاحقاً. يظهر Ollama حتى مع مزود آخر: تحقق من URL والمزود المحفوظين، فالتثبيت لا يثبت المعالجة المحلية.

## الأدوات

ثبت أو حدث MARC Replace؛ فحص الترجمة البرمجية واختصارات staff. تسجيل واحد: `.mrc/.xml` أو نص و`biblionumber` ثم **Preview** وقارن ووافق. الفراغ ينشئ جديداً فاحذر التكرار. تبقى النسخ الموجودة وتستبعد حقول النسخ الواردة. MARCXML السابق ينزل ويرسل للمعرف نفسه للعودة، لا يغني عن backup كامل.

**AI cataloguing**: صور مقروءة للغلاف والعنوان وظهره، JPEG/PNG/WebP وصورة على الأقل. إطار أو هدف، **Read the photos** وانتظر وقارن العنوان والمسؤولية والنشر وISBN والتصنيف والنواقص. صحح MARC قبل الكتابة والتصنيف بالجداول؛ رقم تحقق ISBN لا يثبت الطبعة. المسودة لا تكتب حقول النسخ.

**Install, update or remove the assistant** يستبدل أخبار بداية staff لا OPAC. بحث Koha وقراءات محددة، لا SQL حر. **الاقتراح ليس تنفيذاً:** التسجيل وقبل/بعد والأثر، و**Approve & Execute** بحقوقك مطلوب. تعديل بينهما قد يرفض ويطلب اقتراحاً جديداً. يمكن مراجعة المؤكد؛ حذف المحادثة أو المساعد لا يتراجع عن أفعاله. الحذف يمحو المحادثات ويبقي تاريخ الموافقات.

راقب الأجهزة وKoha ولا تبدأ صوراً جديدة وقت البطء، وفرغ الذاكرة عند المناسبة. لا زمن مضمون. يتلقى المزود البعيد الطلب: سياسة بيانات وصور، لا تجرب بقراء حقيقيين. وسم التكلفة لا يضمن المجانية.

**بحاجة إلى تأكيد:** RAM والقرص والمهلة لكل اختيار وجهاز؛ حد Koha الأدنى ليس ضمان الذكاء الاصطناعي.
