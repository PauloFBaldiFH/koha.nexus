# 6. مظهر OPAC وstaff

[المحتويات](README.md)

**OPAC and Staff Appearance** أو `o` يفصل إعداد العام OPAC عن staff/الداخلي.

**Sync current OPAC settings** يقرأ دون تطبيق. عدل مجموعة في كل مرة. **Preview** يعرض CSS/JavaScript والمحتوى، لا صفحة متصفح كاملة. **Apply** ملخص وموافقة وbackup مسبق. افحص البداية والبحث والتسجيل والدخول والشاشة الصغيرة.

الكتل في `OpacUserCSS/OpacUserJS` وعند الحاجة `IntranetUserCSS/IntranetUserJS`؛ الخاصة محفوظة لكن التعارض المرئي ممكن مع تخصيصات أخرى.

ملمس وضبابية وعتامة وزوايا وألوان وخلفية، فاتح/داكن ومظهر أولي: حافظ على تباين الصور والشفافية. staff شريط علوي وبحث سريع ووحدات وكثافة جدول ونص وتباين. فعّل **Apply color theme to Staff Client**؛ **Copy OPAC preset** يملأ فقط و**Apply** يكتب.

ملف يبلغه الخادم أو خدمة صور معروضة أو HTTPS-URL مباشر. يقبل PNG/JPEG/GIF/WebP/ICO ويرفض SVG. ملف جهاز المستخدم يحتاج إتاحة للخادم. حقوق الصورة ووصف الدخول الميسر؛ صفحة الاستضافة ليست دائماً عنوان الصورة. اضبط الخدمات دون نشر الخاص.

عارض الجديد أو قائمة Koha برقم `shelfnumber=`، عنوان وعدد ونمط وسرعة وتشغيل آلي و**Refresh carousel**. غياب الغلاف ليس حذف التسجيل؛ يعتمد البيانات والصور والشبكة. أزرار OPAC/staff منفصلة بالنص والعنوان والهدف والترتيب و**Add a button** وحذف السطر قبل التطبيق.

الدخول صور ووصف وHTML مرشح من السكربتات والأنماط والأحداث، لا تعليمات سرية. أخبار الجانبين عناوين ونصوص وأزرار خاصة لا تستبدل أخبار المكتبة. تذييل `Field: value`، روابط إضافية نص `|` عنوان، ستة كحد أقصى، عام فقط.

**Remove** موافقة وbackup قبل إزالة كتل المظهر والعودة لـKoha مع تخصيصك؛ ليس restore كاملاً أو تراجعاً عن إدارة أخرى. صحح المجموعة وطبق، واحفظ الخطأ للتشخيص.
