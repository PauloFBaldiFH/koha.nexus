# دليل مستخدم Koha.Nexus

يشرح هذا الدليل، في تسعة فصول، تثبيت Koha.Nexus ولوحته، ولا يحل محل دليل الفهرسة والإعارة الكامل في Koha. كُتب يدوياً بالاستناد إلى البرتغالية والإنجليزية، وقورن بالشيفرة 8c2633d. فحص الشيفرة ليس اختبار تثبيت فعلياً. بقيت أسماء الإجراءات بالإنجليزية لمطابقتها مع الشيفرة؛ قد تعرضها اللوحة مترجمة. لا تترجم الأوامر والمسارات. اقرأ التأكيد قبل استبدال البيانات أو حذفها، ولا تعتمد على أرقام قوائم قديمة.

## بحاجة إلى تأكيد

- التوفر العام ورابط Microsoft Store.
- الحد الأدنى الرسمي لذاكرة Linux؛ الفحص الأولي لا يفرضه شرطاً رقمياً.
- عمل MSIX كاملاً على ARM64؛ ملف manifest خاص بـ x64.
- تنسيقات التصدير الخاصة وإصداراتها دون عينة ومراجعة النتيجة.
- توفر المصادر الخارجية وشروطها عبر الشبكة المحلية.
- ذاكرة الذكاء الاصطناعي ومساحة القرص وزمن الاستجابة حسب الجهاز والاختيار.
- النطاق والشبكة وسياسة المؤسسة للنشر.
- سبب إخفاق محدد دون الرسالة والسجل الكاملين.
