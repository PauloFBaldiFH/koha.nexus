# 4. الاستيراد السحري

[المحتويات](README.md)

## التحضير والصيغ

يقرأ Magic Import الببليوغرافيا والنسخ والقراء والاستناد. التعرف لا يضمن الحقول خصوصاً دون رؤوس أو في المحلي. احتفظ بالأصل وbackup مجرب، وجرب عينة ممثلة بعدة نسخ وتشكيل وفراغات واستثناءات وقارن الأعداد بالمصدر. لا تنشر صادرات القراء.

**Magic Import Tool** أو `i` ثم البطاقة وملف/مجلد يبلغه Linux اللوحة؛ الموجود فقط بجهاز المتصفح/الطرفية ليس تلقائياً في الخادم.

| المدخل | التحقق |
| --- | --- |
| MARC21 ISO 2709 وMARCXML ونص MARC | عناوين وحروف واستناد ونسخ؛ يقبل MarcEdit `.mrk` دون تحويل لمجرد الامتداد. |
| CSV/TSV و`.xlsx/.xls/.ods/.dbf` | فواصل ورؤوس وقيم ووجهات. |
| JSON/XML جدولي | البنية؛ XML عام ليس بالضرورة MARCXML. |
| SQL جدولي ولو دون رؤوس | قراءة بيانات وعلاقات، لا تنفيذ برنامج ترحيل؛ راجع الغموض. |
| ISIS | PostgreSQL معروف مع `acervo`؛ صدر CDS/ISIS `.mst` من WinISIS بصيغة ISO 2709. |
| Biblioteca Fácil | Backup/مجلد معروف والجداول المرتبطة معاً؛ افحص التسجيلات والأشخاص والإعارات والحجوزات منفصلة. |
| Backup كامل Koha | إلى restore لا إضافة التسجيلات. |

PostgreSQL آخر خصوصاً `pg_dump` ثنائي ليس MariaDB جاهزة. عند الرفض صدر MARC/جداول من المصدر. افحص كل عضو للأرشيف؛ PDF والصور والوثائق والبرامج ليست تصديراً ببليوغرافياً لهذا القارئ.

## المطابقة والبيانات

تحقق **Bibliographic/Patrons/Authorities**. شبكة ووجهات، فاصل أو **Ctrl+Up/Down** للارتفاع. إبقاء/إعادة توجيه/نص ثابت/تجاهل؛ افهم العلاقات قبل حذف ID. **Values of this Koha** رموز ومكتبة/نوع/فئة افتراضية واستبدالات مصدر/هدف. **Record preview** النتيجة، **Check the whole file** إعداد وتحقق كامل دون الاستيراد حينها. ملف تعريف اسم/**Save** واختيار/**Use**، راجعه لتغير البنية. **Apply/Ctrl+S** يقبل المطابقة لا الكتابة النهائية. **Skip: import as it is/Esc** يتجاوز المطابقة لا يلغي الجميع. التجميع وتصحيح النص يحتاجان معاينة، لا تغييراً أعمى للاختصارات والأسماء والرموز.

يحفظ `952` مع مطابقة المكتبة/النوع عند الطلب؛ لا تبدل رمزاً صالحاً فقط لموافقة الافتراضي. افحص barcode والمكتبة المالكة/الحالية ورقم الطلب والنوع والموقع والاقتناء. قد تختلف `949/852/950/990` المحلية بين Pergamum/Biblivre. ملاحظة الإيداع القانوني `DL`/تاريخ لا تنشئ نسخة محلية تلقائياً؛ راجع الاستبعادات والدليل المستقل للمخزون. دون barcode تراجع افتراضياً؛ التوليد يحتاج اختياراً وهوية ثابتة للترحيل/المصدر، دون إعادة ترقيم صامتة للتصادم. علاقة SQL يجب التعرف إليها لا تخمينها من ترتيب الأعمدة/الصفوف؛ أصلحها قبل الاستيراد.

**Patrons**: اسم وبطاقة واتصال وعنوان وتواريخ ومكتبة وفئة موجودة. E-mail/CPF/تاريخ قرائن فقط؛ الميلاد والتسجيل والانتهاء متشابهة. تحديث الموجود يسأل بمطابقة البطاقة، لا إضافة الجديد فقط؛ لا تخمن الحقوق والمصادقة. **Authorities**: ID، صيغة معتمدة، بدائل، علاقات، نوع؛ تغيير النمط لا يخلق المفقود.

اقرأ الأعداد والرفض والأسئلة. الموجود يبقى مع نسخ جديدة أو يستبدل أو ينشأ دون مقارنة. **فشل لاحق قد يبقي المراحل الأولى مستوردة.** احتفظ بالنتيجة والسجل وافحص المراحل والعينة والنسخ والأشخاص والعلاقات قبل التكرار. **Library tools > Undo a MARC import** لـMARC لا لكل القراء والإعارات والحجوزات. القاعدة الكاملة وفق Backup center.

**بحاجة إلى تأكيد:** بنية تصدير مغلقة أو إصدار محدد دون عينة ومراجعة.
