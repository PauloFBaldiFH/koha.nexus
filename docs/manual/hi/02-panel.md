# 2. शुरुआत और पैनल

[विषय-सूची](README.md)

## पैनल खोलना और चलाना

तैयार Debian या Ubuntu पर चलाएँ:

```bash
sudo config.sh
```

Windows में **Koha** चिह्न या MSIX अनुप्रयोग खोलें। पहली बार भाषा पूछी जा सकती है। Textual तैयार न होने पर पुराना पैनल मिल सकता है; पुराने मेनू के अंक वर्तमान कार्डों के स्थायी पते नहीं हैं।

तीर कुंजियों से साइडबार का भाग चुनें, Enter या क्लिक से खोलें। केवल चयन बदलने से कार्य नहीं चलता। सामग्री क्षेत्र में सही कार्ड खोलें और प्रश्न पढ़ें। Tab नियंत्रणों के बीच जाता है। अक्षर वाले मुख्य-पृष्ठ शॉर्टकट से पहले लिखने वाले खाने से बाहर आएँ।

| कुंजी | मुख्य पृष्ठ का कार्य |
| --- | --- |
| d | Control Dashboard खोलना |
| b | Backup center खोलना |
| c | Debian टर्मिनल खोलना |
| Ctrl+B | साइडबार दिखाना या छिपाना |
| q | पैनल से बाहर निकलना |

खाली पैनल से बाहर आना सर्वर बंद करना नहीं है। कार्य चल रहा हो तो उसी स्क्रीन की रद्द करने की व्यवस्था मानें। स्थापना और restore के कुछ चरण रद्द नहीं हो सकते; खिड़की बंद करना सुरक्षित रोक नहीं है।

## स्थिति और पते

**Control Dashboard** में Koha, उपलब्ध RAM, खाली डिस्क, नवीनतम backup का दिन/आकार और स्थानीय, LAN तथा विन्यस्त इंटरनेट पते मिलते हैं। MariaDB, Apache, RabbitMQ, Memcached, Koha और HTTP की स्थिति उपयोगी है, लेकिन पूरे पुस्तकालय कार्य का परीक्षण नहीं।

नई फ़ाइल और पिछली रात्रि के कार्य का परिणाम अलग चलनों से हो सकते हैं। नई फ़ाइल रहते हुए भी रात्रि कार्य विफल हो सकता है। HTTP उत्तर वेब स्थापना पूरी होने का प्रमाण नहीं। **Refresh** फिर पढ़ता है; **Restart Koha** सेवा सुधार/पुनः आरंभ माँगता है; **Export diagnostics** जाँच विवरण निकालता है। पुराने इंस्टॉलर में कुछ बटन अनुपलब्ध हो सकते हैं। पुनः आरंभ से पहले उपयोगकर्ताओं पर असर देखें।

सर्वर पर सामान्य OPAC `http://localhost/` और staff `http://localhost:8080/` हैं। दूसरे कंप्यूटर का localhost उसी कंप्यूटर को दर्शाता है। पैनल का नेटवर्क पता लें। WSL के NAT के कारण LAN पहुँच न होने की सूचना आए तो Windows नेटवर्क तैयारी की जाँच करें। पता कार्ड URL खोल या कॉपी कर सकते हैं।

## पुस्तकालय कार्य शुरू करने से पहले

staff में Koha वेब इंस्टॉलर दिखे तो पहले उसे पूरा करें। संस्करणों के चरण अलग हो सकते हैं। उसके बाद **Koha settings & parameters > Create super librarian** अलग खाता-निर्माण खोलता है। निजी जानकारी वहीं भरें और व्यापक अधिकार सीमित रखें।

स्थिति ताज़ा करें, staff/OPAC खोलें, खोज चलाएँ और backup बनाकर जाँचें। सर्वर से बाहर की प्रति कहाँ है और कौन उसे वापस ला सकता है, तय करें। बाहर सफल प्रतिलिपि होना वास्तविक स्थानांतरण और जाँच पर निर्भर है; डैशबोर्ड अकेले इसकी गारंटी नहीं देता।
