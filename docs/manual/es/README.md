# Manual de usuario de Koha.Nexus

Este manual describe el instalador y el panel Koha.Nexus; no sustituye el manual Koha de catalogación y circulación. Texto redactado a mano a partir de portugués e inglés y comprobado con el código de `755c1d8`. La lectura del código no equivale a una instalación probada en hardware real.

Los nombres de acciones se conservan en inglés para identificar exactamente las claves del código; su panel puede mostrarlos traducidos. Los comandos y las rutas no se traducen. Una advertencia destructiva significa que se pueden sustituir o borrar datos: lea la confirmación. “Pendiente de confirmar” identifica lo que no puede garantizarse sólo con el código. No siga numeraciones de menús antiguos.

## Pendiente de confirmar

- Disponibilidad y URL pública de Microsoft Store.
- Mínimo oficial de RAM Linux, sin umbral numérico impuesto por el preflight actual.
- Funcionamiento completo del paquete MSIX en ARM64; manifiesto x64.
- Layouts propietarios/versiones de exportación sin muestra y revisión.
- Disponibilidad y condiciones de las fuentes externas desde la red local.
- RAM, disco y latencia de IA según hardware y selección.
- Dominio, red y política institucional de publicación.
- Causas de fallos concretos sin mensaje completo y log.
