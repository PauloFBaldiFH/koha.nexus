# 1. Встановлення

[Зміст](README.md)

## Середовище та вимоги

У Windows Koha працює всередині Debian через WSL 2. Засоби Windows готують середовище, відкривають панель та інтегрують програму. У Debian/Ubuntu служби й панель встановлюються безпосередньо. Наявний каталог відкривайте панеллю, а не повторним встановленням.

| Середовище | Перевірки в коді |
| --- | --- |
| Windows | Windows 10 версії 2004, збірка 19041 або новіша, чи Windows 11; 64 біти, увімкнена віртуалізація; RAM 8 GB, рекомендовано 12 GB; вільно 10 GB на диску встановлення, рекомендовано 20 GB. |
| Debian/Ubuntu | Debian 11/12/13 чи Ubuntu 22.04/24.04; зазначені amd64/arm64; менше 5 GB блокує, від 5 до менше 10 GB попереджає, від 10 GB перевірку пройдено. |

Каталог, вкладення, індекси та backup потребують додаткового місця. **RAM Linux потребує підтвердження:** настанова рекомендує виділеному серверу 4 GB, краще 8 GB; робочому столу/віртуалізації 8 GB, краще 12 GB. Поточна перевірка Linux не вимагає числового мінімуму RAM. Успіх не гарантує кожного навантаження. Windows враховує апаратно зарезервовану пам’ять: визначені пороги 7,5 та 11,5 GB.

Linux вимагає адміністративних прав і доступу до сховища пакетів Koha. TCP 80/8080 використовують OPAC/staff. Якщо зайняті, пропонується зупинити відповідні служби. **Погоджуйтеся лише за допустимості переривання.**

## Windows: PowerShell

Увійдіть в адміністративний обліковий запис Windows, який користуватиметься Koha. Відкрийте PowerShell від адміністратора в тому самому записі:

```powershell
irm https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/main/windows/install.ps1 | iex
```

Якщо підвищення прав просить чужий запис, скасуйте та увійдіть правильно: WSL належить запису встановлення. Прочитайте перевірки, виправте вимкнену віртуалізацію. У вікні дайте відповіді про обліковий запис Debian, окремий від бібліотечного Koha.

Дочекайтеся WSL 2/Debian. Запитане перезавантаження реєструє продовження за наступного входу Windows. Виберіть мову/**Install Koha server**. Після завершення в панелі вийдіть штатно й дочекайтеся інтеграції Windows.

Типово `C:\Koha`, старе встановлення може зберегти `C:\KohaEasy`. Не переносьте теку для виправлення переривання. Збережіть помилку: завершені етапи записуються, повторний запуск може продовжити чи відкрити панель для завершення. Руйнівне перевстановлення від цього не стає безпечним.

## MSIX

Пакет готує те саме WSL; встановлений пакет не означає готові сервер/базу. **Звичайний PowerShell без попереднього підвищення прав**:

```powershell
irm https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/main/windows/msix/instalar_msix.ps1 | iex
```

Помічник завантажує вказаний кодом пакет, перевіряє походження, запитує адміністративний дозвіл і встановлює поточному користувачу. Відмов не ігноруйте. Дочекайтеся підготовки, завершіть майстер сервера, вийдіть штатно та дочекайтеся ярликів, завдань і мережі Windows. Передчасне закриття не завершує Koha: відкрийте знову.

**Потребує підтвердження:** публічна доступність/адреса Microsoft Store; код пакування не доводить публікації. Повна робота MSIX на ARM64 також не підтверджена: маніфест x64, підтримка arm64 Linux недостатня. Маніфест допускає старішу Windows, ніж увесь процес WSL; плануйте за повними вимогами вище.

## Debian/Ubuntu

У терміналі сервера:

```bash
wget https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/refs/heads/main/installer
sudo bash installer
```

З локальним репозиторієм і перекладами:

```bash
git clone https://github.com/PauloFBaldiFH/koha.nexus.git
cd koha.nexus
sudo bash installer
```

Мова/**Install Koha server**. Спочатку виправте критичні помилки; попередження не є гарантією потужності. WSL потрібна версії 2 із запущеним systemd; WSL 1 відхиляється. У Windows краще скористатися описаною підготовкою з підказками.

## Встановлення в панелі

Відкрийте **Install Koha server**, зачекайте на перевірку/звіт, оцініть вплив звільнення портів. Перевірте цільовий комп’ютер і часовий пояс або регіон/місто. **Є примірник Koha: зупиніться та перевірте.** Перевстановлення видаляє базу/налаштування, вимагає додаткового підтвердження й точно `REINSTALL`. Не для простого відкриття/оновлення панелі.

Не закривайте: скасувати не можна. Оцінка 10–30 хвилин залежить від обладнання/мережі. Прочитайте результат/звіт: завершення з проблемами не означає справні служби. Оцініть пропонований перезапуск, а в MSIX зачекайте й на продовження Windows. Приватні дані результату не публікуйте в документах чи зверненнях.
