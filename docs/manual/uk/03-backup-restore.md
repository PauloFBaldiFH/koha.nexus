# 3. Backup і restore

[Зміст](README.md)

## Центр і типи копій

**Backup center**, `b`: дата, розмір, результат, **Compression**, картки.

| Картка | Мета |
| --- | --- |
| Download latest backup | Копія найновішого знайденого файла |
| Generate manual backup and download to PC | Створити, перевірити, перенести базу |
| Export MARC21 records now | Бібліографія й авторитетні записи |
| Restore database | Замінити поточну базу |
| Configure cloud backup | Зовнішнє надсилання |
| Test integrity of latest backup | Тимчасовий пробний імпорт |

**Restore database є карткою**, не верхньою кнопкою чи окремим головним пунктом. Результат стосується ночі, дата/розмір найновішого файла, можливо іншої операції.

SQL містить базу Koha, не повний образ Windows/Debian. MARC21 містить бібліографію/авторитетні записи у `.tar.gz`, не замінює SQL для читачів/обігу. Перед restore бази з таблицями створюється перевірена захисна копія; порожня може пропустити.

Автоматичний SQL/захист `/var/backups/koha_sql`, MARC `/var/backups/koha_marc`. Ручний має окреме місце, типово `backups` у визначеній домашній теці. `.part` тимчасовий до перевірок/перейменування.

## Стиснення й перенос

**Compression**: gzip `.sql.gz` сумісний, Zstandard `.sql.zst` швидкий/менший для великих каталогів, XZ/LZMA `.sql.xz` найменший/повільніший. Вибір зберігається відразу без іншої кнопки, для нових нічних/ручних/захисних, без повторного стиснення старих. Немає програми/збій встановлення: можливий gzip, читайте фактичний формат. Restore незалежно впізнає `.sql/.sql.gz/.sql.zst/.sql.xz`; розширення не доводить зміст.

**Generate manual backup and download to PC**: перевірте теку сервера для запису, **Save backup**, зачекайте створення/контролю; під час запису/копії екран не закривається. Перевірте назву/розмір/шлях. WSL **Save to Windows Downloads/Choose folder in Windows**, віддалено показану команду виконайте на власному комп’ютері. Перевірте отримання, **Finish and exit**.

Windows-кнопки лише WSL; чужі команди не копіюйте, залежать від сервера/файла. Інший backup/restore: чекайте, не обходьте загальне блокування паралельною зовнішньою задачею. **Download latest backup** бере наявне, не створює. Desktop-Linux/WSL пробує Downloads, SSH може показати локальну команду. Немає файла: створіть вручну.

## Тест, MARC, хмара

**Test integrity of latest backup**: дата/файл, **Choose another file**, згода й тимчасовий імпорт. Успіх показує таблиці/записи/читачів без заміни робочої бази. Стосується цієї копії/середовища; збережіть доступ до того самого переданого файла.

**Export MARC21 records now** підтвердьте, дочекайтеся пакета бібліографії/авторитетних записів, перевірте шлях/зміст/перенос. Koha працює далі; налаштована хмара звітує надсилання. SQL залишайте для повної бази.

**Configure cloud backup**: два шляхи Google Drive та зокрема OneDrive/MEGA/S3. Авторизація на сервері/іншому комп’ютері, лише показані URL/інструкції. S3 розрізняє сервіс, регіон/endpoint, bucket. Чекайте реального пробного надсилання й отримання, помилкове налаштування ненадійне. Приватні дані тільки у встановленні, не відкриті тексти/зображення/підтримка; файли зберігання тут не називаємо. SQL щодня 23:00, MARC неділя 03:00 за сервером типово, cron може відрізнятися.

## Руйнівний restore

**Підтвердження дозволяє заміну поточної бази.** Заплануйте обслуговування й зовнішню копію; панель не виконує цю додаткову пораду за вас.

**Restore database**: доступний файл, перенос за потреби. WSL може спочатку копіювати Windows у Linux. Читайте доступність/вміст/цілісність/місце, з’ясуйте підозрілий/неповний файл попри розширення. Знову перевірте при згоді: до неї можна відмовитися, після чекати без закриття, скасування немає.

Спочатку тимчасовий SQL-імпорт із перевіркою основних таблиць/кількості, збій зупиняє до заміни. Наявним таблицям перевірена SQL-копія `pre_restore_safety_backup_` з датою/часом/стисненням; її помилка не повинна видаляти поточну базу. Порожня може пропустити.

Потім зупинка клієнтів, створення/імпорт, схема, синхронізація пошуку, індекси, служби. Збережену тему пробують застосувати за доступності. Помилка тесту/копії не означає заміну. На створенні/імпорті/схемі можливе повернення за етапом/копією, **але rollback також може не спрацювати**. Індекс може впасти після restore бази без повернення старого каталогу.

Збережіть повідомлення, `/var/log/koha-easy-install/restore.log`, `/var/log/koha-easy-install/restore-import.log`, для індексу `/var/log/koha-easy-install/zebra-rebuild.log`. Картка центру замість старих номерів, технічна допомога за невизначеності. Перевірте dashboard/записи/пошук OPAC/staff. Завершення SQL не підтверджує зовнішні файли.
