# 6. Оформлення OPAC і staff

[Зміст](README.md)

**OPAC and Staff Appearance**, `o`, окремі налаштування публічного OPAC і staff/інтранету.

**Sync current OPAC settings** читає без застосування. Змінюйте групами. **Preview** показує CSS/JavaScript/вміст, не повне відтворення браузера. **Apply** підсумок/згода з попереднім backup. Перевірте початок/пошук/запис/вхід, також малий екран.

Блоки в `OpacUserCSS/OpacUserJS`, за потреби `IntranetUserCSS/IntranetUserJS`; власні залишаються, можливі візуальні конфлікти з іншими змінами.

## Оформлення й матеріали

Текстура/розмиття/непрозорість/кути/барви/тло, світла/темна й початкова тема: зберігайте контраст при малюнку/прозорості. Staff: верхня смуга/швидкий пошук/модулі/щільність таблиць/текст/контраст. **Apply color theme to Staff Client** увімкнути; **Copy OPAC preset** лише заповнює, **Apply** пише.

Доступний серверу файл, запропонований сервіс чи пряма HTTPS-URL. PNG/JPEG/GIF/WebP/ICO приймаються, SVG відхиляється. Файл лише на клієнті зробіть доступним серверу. Права на зображення/доступний опис входу; сторінка хостингу не завжди адреса картинки. Налаштуйте зовнішні сервіси без оприлюднення приватних відомостей.

Карусель новинок/списку Koha з `shelfnumber=`; назва/кількість/стиль/швидкість/autoplay/**Refresh carousel**. Нема обкладинки не означає видалений запис: залежить від даних/обкладинок/мережі. Кнопки OPAC/staff окремо, текст/адреса/ціль/порядок, **Add a button**, видалення рядка до застосування.

Вхід: зображення/опис/HTML без скриптів/стилів/подій, не таємні внутрішні вказівки. Новини кожного боку мають власні назву/текст/кнопки, не замінюють бібліотечні. Підвал `Field: value`, додаткові посилання текст `|` адреса, максимум шість, лише публічне.

**Remove** підтверджує й робить backup перед вилученням блоків теми, повертає Koha-вигляд зі своїми змінами. Не повний restore/скасування іншого адміністрування. Виправте потрібну групу й застосуйте, помилку збережіть для діагностики.
