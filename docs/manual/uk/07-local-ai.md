# 7. Локальний ШІ

[Зміст](README.md)

**AI**, `a`: постачальник, Ollama, фотокаталогізація MARC Replace, staff-асистент. Налаштування не встановлює інструменти автоматично.

## Локальна робота

Попередження CPU/RAM: Koha може сповільнитися. **Ollama on this server > Check Ollama**, якщо немає **Install Ollama**. Вибір/**Download** вимагає мережі/диска; назви моделей не фіксуємо, список змінюється. **Local Ollama**, URL (типово `http://127.0.0.1:11434`), **Use for chat/Use for cataloguing**. Фото потребує зору, самого тексту мало. **Test connection/Save**, **F5/Ctrl+S**; заповнення не зберігає. Порожній чат бере зоровий вибір. **Load models** питає постачальника, вбудований резервний список позначається.

Встановлене займає диск, завантажене RAM. **Free memory** вивантажує без видалення, потім може завантажити знов. Ollama видима з іншим постачальником: перевірте збережені URL/постачальника, встановлення не доводить локальне опрацювання.

## Інструменти

MARC Replace встановити/оновити, перевірка компіляції/ярликів staff. Один запис: `.mrc/.xml` чи текст, `biblionumber`, **Preview**, порівняти/підтвердити. Порожньо створює новий, уникайте дубля. Примірники залишаються, вхідні поля одиниць виключено. Попередній MARCXML можна завантажити/подати тому самому ID для повернення, не заміна цілого backup.

**AI cataloguing**: чіткі обкладинка/титул/зворот, JPEG/PNG/WebP, мінімум одна. Framework/ціль, **Read the photos**, чекати та порівняти назву/відповідальність/вихідні дані/ISBN/клас/пропуски. Виправте MARC до запису й класифікацію перевірте в таблицях; цифра ISBN не доводить видання. Чернетка не пише поля примірників.

**Install, update or remove the assistant** замінює новини початку staff, не OPAC. Koha-пошук/задані читання, не довільний SQL. **Пропозиція ще не виконана:** запис/до-після/наслідок, **Approve & Execute** із власними правами. Проміжна зміна може відхилити/вимагати нову. Підтверджені дії доступні; вилучення розмови/асистента не скасовує. Видалення стирає розмови, зберігає історію схвалень.

Стежте за обладнанням/Koha, при повільності не запускайте нові фото, звільняйте пам’ять доречно. Нема гарантованого часу. Віддалений постачальник отримує запит: політика даних/зображень, не тестуйте справжніми читачами. Позначка ціни не гарантує безкоштовність.

**Потребує підтвердження:** RAM/диск/затримка за вибором/обладнанням; мінімум Koha не гарантує ШІ.
