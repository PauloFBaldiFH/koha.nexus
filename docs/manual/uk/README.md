# Посібник користувача Koha.Nexus

Посібник описує встановлювач і панель Koha.Nexus, не замінює повної документації Koha щодо каталогізації та видачі. Текст написано вручну за португальським/англійським джерелом і перевірено за кодом `d81eb64`. Перегляд коду не є випробуванням встановлення на справжньому обладнанні.

Назви дій залишено англійськими для точного зіставлення ключів коду; панель може показувати переклад. Команди й шляхи не перекладаються. Руйнівні операції можуть замінити/видалити дані: читайте підтвердження. «Потребує підтвердження» позначає те, чого сам код не гарантує. Не використовуйте старих номерів меню.

## Потребує підтвердження

- Публічна доступність і URL Microsoft Store.
- Офіційний мінімум RAM Linux, не встановлений числовою перевіркою.
- Повна робота MSIX на ARM64; маніфест x64.
- Закриті структури/версії експорту без зразка та перевірки.
- Доступність і умови зовнішніх джерел із місцевої мережі.
- RAM, диск і час ШІ за обладнанням/вибором.
- Домен, мережа й правила публікації установи.
- Причини збоїв без повного повідомлення та журналу.
