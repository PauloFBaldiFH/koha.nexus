# 2. Перші кроки та панель

[Зміст](README.md)

## Відкриття й навігація

У підготовленій Debian/Ubuntu:

```bash
sudo config.sh
```

Windows: значок **Koha** або MSIX. Перший запуск може питати мову. Якщо підготовка Textual не вдалася, можлива класична панель. Посібник описує переважно Textual, а не старі номери меню.

Стрілками позначте розділ, **Enter** або клацання відкриває. Саме виділення нічого не запускає. Відкрийте картку завдання, читайте питання. **Tab** пересуває фокус; перед буквами швидкого доступу вийдіть із текстового поля.

| Клавіша | Дія |
| --- | --- |
| `d` | Control Dashboard |
| `b` | Backup center |
| `c` | Термінал Debian |
| `Ctrl+B` | Показати/сховати бічну панель |
| `q` | Вийти з панелі |

Вихід із неактивної панелі не вимикає сервера. Під час роботи дотримуйтеся її можливостей скасування. Встановлення/restore мають етапи без скасування, примусове закриття небезпечне.

## Стан і адреси

Dashboard показує Koha/доступну пам’ять, останній backup з датою/віком/файлом, вільний диск, адреси, MariaDB, Apache, RabbitMQ, Memcached, Koha та HTTP. Backup враховує вік і останній нічний результат: новий файл може існувати після нічного збою. Читайте обидва; сприятливий показник не замінює restore-тест. HTTP не доводить завершеного вебмайстра чи всіх бібліотечних функцій.

**Refresh** перечитує. **Restart Koha** просить ремонт/перезапуск із врахуванням користувачів; **Export diagnostics** готує підтримку. Кнопки можуть бути недоступні, якщо поточний встановлювач не підтримує завдання.

Адресні картки відкривають/копіюють URL; без запуску браузера вставте у власному. На сервері OPAC `http://localhost/`, staff `http://localhost:8080/`, порти 80/8080. На іншому комп’ютері використовуйте мережеву адресу, не його `localhost`. WSL NAT/недоступна LAN: перевірте підготовку Windows із відповідальним, не припускайте загальної доступності.

Якщо з’явився вебвстановлювач Koha, завершіть до роботи; екрани залежать від версії. **Create super librarian** у **Koha settings & parameters** створює запис, приватні значення лише там.

Перед роботою оновіть dashboard, перевірте компоненти/адреси, відкрийте OPAC/staff правильно, створіть/перевірте backup і зовнішню копію з відповідальним за повернення. Останнє є експлуатаційною порадою: потрібен завершений перевірений перенос.
