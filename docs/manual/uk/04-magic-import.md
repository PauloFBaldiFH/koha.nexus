# 4. Магічний імпорт

[Зміст](README.md)

## Підготовка й формати

Magic Import читає бібліографію, примірники, читачів і авторитетні записи. Впізнаний формат не гарантує поля, особливо без заголовків/локальні. Зберігайте оригінал/перевірений backup, репрезентативну вибірку з кількома примірниками, діакритикою, порожніми значеннями/винятками, порівняйте кількості джерела. Експорти читачів не публікуйте.

**Magic Import Tool**, `i`, картка та файл/тека доступні Linux панелі; файл лише на комп’ютері браузера/термінала не з’являється автоматично на сервері.

| Вхід | Перевірка |
| --- | --- |
| MARC21 ISO 2709, MARCXML, текст MARC | Назви/символи/авторитетні/примірники; `.mrk` MarcEdit впізнається без перетворення лише через розширення. |
| CSV/TSV, `.xlsx/.xls/.ods/.dbf` | Роздільник/заголовки/значення/цілі. |
| Табличні JSON/XML | Структура, довільний XML не обов’язково MARCXML. |
| Табличний SQL, навіть без заголовків | Читає дані/зв’язки, не виконує міграційної програми; перевірте неоднозначність. |
| ISIS | Впізнаний PostgreSQL з `acervo`; головний CDS/ISIS `.mst` експортувати WinISIS ISO 2709. |
| Biblioteca Fácil | Впізнаний backup/тека, пов’язані таблиці разом, записи/читачі/видачі/замовлення окремо. |
| Повний backup Koha | До restore, не додавання записів. |

Інший PostgreSQL, особливо бінарний `pg_dump`, не готова MariaDB. При відмові експортуйте MARC/таблиці у джерелі. Кожен елемент архіву перевірити. PDF/малюнки/документи/програми не є бібліографічним експортом цього засобу.

## Зіставлення

Перевірте **Bibliographic/Patrons/Authorities**. Сітка/цілі, висота роздільником чи **Ctrl+Up/Down**. Залишити/перенаправити/сталий текст/пропустити, зрозуміти зв’язки перед видаленням ID. **Values of this Koha**: коди, типові бібліотека/тип/категорія, заміни джерело/ціль. **Record preview** результат, **Check the whole file** повна підготовка/валідація без імпорту. Профіль назва/**Save**, вибір/**Use**, перегляд при новій структурі. **Apply/Ctrl+S** приймає зіставлення, не фінальний запис. **Skip: import as it is/Esc** пропускає зіставлення, не скасовує все. Групування/редагування тексту попередньо перегляньте, не змінюйте сліпо скорочення/імена/коди.

## Дані

`952` зберігаються, бібліотеку/тип можна за запитом переназначити; чинний інший код не міняйте тільки заради типового. Barcode, домашня/поточна бібліотека, шифр, тип, місце, надходження. Локальні `949/852/950/990` у Pergamum/Biblivre можуть означати різне. Позначка обов’язкового примірника `DL`/дата не створює автоматично місцеву одиницю: перевірте вилучення й незалежні інвентарні свідчення. Нема barcode: типово перегляд; створення вимагає вибору/сталої тотожності міграції/джерела, без прихованої перенумерації колізій. SQL-зв’язок слід впізнати, не вгадувати за позицією/порядком; виправте до імпорту.

**Patrons**: ім’я/прізвище/квиток/контакт/адреса/дати/бібліотека/наявна категорія. E-mail/CPF/дата лише ознаки, народження/реєстрація/закінчення схожі. Оновлення наявних запитується за квитком, відмінне від лише нових; права/автентифікацію не вгадувати. **Authorities**: ID, затверджена форма, варіанти, зв’язки, тип; зміна режиму не створює відсутніх відомостей.

Читайте кількості/відмови/питання. Наявне залишити з новими примірниками, замінити чи створити без порівняння. **Пізній збій може залишити попередні етапи імпортованими.** Збережіть підсумок/журнали та перевірте завершені етапи/вибірки/одиниці/людей/зв’язки перед повтором. **Library tools > Undo a MARC import** для MARC, не всіх читачів/видач/замовлень. Повна база за правилами Backup center.

**Потребує підтвердження:** конкретна закрита структура/версія експорту без зразка й перевірки.
