# 5. Збагачення та Z39.50/SRU

[Зміст](README.md)

## Збагачення

Імпорт переносить експорт, збагачення доповнює або знаходить нову книгу. Однакова назва потребує бібліографічного перегляду. **Library tools > Enrich from world catalogues**, `n`; старий пакетний екран не поточний шлях меню.

`all` або `biblionumbers`, наприклад `101, 102, 500-510`, **Search**. Стежте за завданням/серверами; великі у фоні можуть продовжити після перезапуску з доступною машиною. **Pause/Resume** не скасовує застосоване. Звіт: теми/класи/примітки/фізичний опис порівняти. **Search more servers** нові джерела, **Choose donor** донор груп полів. **Apply** після перегляду/згоди, пошук/звіт ще не пишуть.

Прямий Z39.50 має ліміти/збої, відсутність результату не доводить відсутності книги. Нема загального ліміту 50 записів: поріг захисту застосування, копії записів для малих, перевірений повний backup для великих. **Revert** повертає версії за захистами, зберігає пізніше редаговані, не глобальний restore чи скасування всіх чужих змін.

## Нове й авторитетні

ISBN/назва з автором/роком, **Find**, перевірити/обрати. **Import as new record** додає після згоди без заміни однакового ISBN. Вилучає місцеві `9XX` донора, фіксує джерело, аби чужі примірники не стали вашими. Перевірте запис і створіть місцеві одиниці звично; партія через **Undo a MARC import**.

**Enrich & standardize authorities**, `h`: охоплення, точні/близькі форми. Близькі пропонують виправлення/попередні авторитетні записи, особливо перевірити. Спочатку власні Koha, далі база збагачення/прямі сервери; бразильські пріоритетні, теми лише звідти, не гарантія місцевої політики. **Apply** створює потрібні записи/зв’язки з backup, зберігає зміни після звіту; Revert залишає створені авторитетні записи, якщо ще пов’язані.

## Сервери

**Z39.50 / SRU servers**, `z`: вхідний дозволяє сторонній пошук і змінює порт firewall. Спільнотна мережа відмінна від прямих джерел. **Reset/Reset all** дозволяє повтор, не лагодить віддалене. Пробіл обирає, **Scan** шукає справжній запис, **Add to Koha** додає обрані робочі. SRU у налаштуваннях не означає SRU кожного запиту; зовнішній пошук не вимагає відкритого входу.

**Потребує підтвердження:** доступність/покриття/умови кожного джерела з місцевої мережі під час використання.
