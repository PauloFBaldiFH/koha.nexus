# 4. 智能导入

[目录](README.md)

## 先保留原件

**Magic Import Tool** 通过 i 或侧栏打开。保留原始文件和已测试的 Koha backup，先用涵盖多册、重音、空字段及异常记录的代表样本，对比来源与预览数量。读者导出不可公开。文件必须可被面板所在 Linux 访问，浏览器电脑上的文件不会自动传到远端。

支持 MARC21 ISO 2709、MARCXML、文本 MARC/MarcEdit `.mrk`、CSV/TSV、XLSX/XLS、ODS、DBF、表格 JSON/XML 及可识别的表格 SQL。`.mrk` 不因扩展名就必须转换，任意 XML 也不一定是 MARCXML。SQL 被读取为数据，不作为迁移脚本执行。

ISIS 专用读取器识别含 `acervo` 表的 PostgreSQL 导出；`.mst` 应从 WinISIS 导出 ISO 2709，不能直接当馆藏读取。Biblioteca Fácil 需保留关联表，分别检查书目、读者、借阅和预约。完整 Koha backup 会转向替换数据库的 restore。其他系统的 PostgreSQL 或二进制 pg_dump 不是可直接供 MariaDB 恢复的文件；拒绝读取时改从原系统导出 MARC 或表格。归档须逐成员检查。PDF、图片、普通文档及可执行文件不是可用的书目导出。

## 手动映射

检查 **Bibliographic**、**Patrons**、**Authorities** 模式，误判时手动切换。选择样例字段，检查目的字段及功能：保留、重定向、固定文字或排除。标识符可能连接其他表，不应随便丢弃。拖动分隔线或用 Ctrl+Up/Ctrl+Down 缩放网格；这不是移动到另一条记录的快捷键。

**Values of this Koha** 显示目标馆、资料类型、读者类别的有效代码和默认值，也要核对来源到目标的代码映射。**Record preview** 只看样例；**Check the whole file** 准备并验证整个文件，此时不写入 Koha。命名映射配置后用 **Save** 保存，选择后用 **Use** 加载；来源结构改变时仍需复核。

**Apply** 或 Ctrl+S 接受映射并继续准备，不是最终导入确认。Esc 或 **Skip: import as it is** 跳过手动映射，不会取消全部流程。批量文字变换和去重应先预览，避免破坏缩写、姓名和编码。

## 馆藏、读者与规范记录

原生 `952` 应保留，只有在请求且目标代码有效时才映射馆与类型。默认值不同不等于原值无效。`949`、`852`、`950`、`990` 在不同系统含义不同，需核对条码、所属馆、现藏馆、索书号、类型、位置和日期。带 `DL` 的法定呈缴注记不应自动成为本馆实物，须有独立证据。

缺条码默认需要复核。生成替代码须明确选择并具备稳定来源/迁移标识，不能悄悄改号绕过碰撞。导入前检查缺失、重复及与目标冲突的条码。SQL 的书目与册必须有可识别关联，不能按列位置或行顺序猜测。

读者模式应逐项检查姓名、卡号、联系方式、地址、出生/登记/到期日期、馆和类别。CPF、邮箱和日期形式只是线索；同一格式不证明日期用途。按卡号更新旧读者与只新增不同，应读清选择；不得凭猜测赋管理员权限或认证信息。

规范模式核对标识、规范标目、变体、关系和类型。切换模式不会补出来源没有的数据。

## 确认与事后检查

阅读输出、数量、拒绝项及未解决的馆/类型/类别问题，再批准写库。已有书目可选择保留记录只增新册、替换记录，或不比较而每条新建；不要无意重复批次。

后阶段失败不保证前阶段回退，可能已部分导入。保存日志、比对各阶段数量后再决定重试。检查 Koha 中的书目、册、读者和规范链接。**Undo a MARC import** 处理 MARC 批次，不是读者、借阅、预约的通用撤销。特定系统版本或私有布局的兼容性须用样本和结果确认。
