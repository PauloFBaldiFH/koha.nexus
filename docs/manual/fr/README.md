# Manuel utilisateur de Koha.Nexus

Ce manuel décrit l’installateur et le panneau Koha.Nexus ; il ne remplace pas le manuel Koha pour catalogage et circulation. Texte rédigé à la main à partir du portugais et de l’anglais, vérifié avec le code `755c1d8`. Une lecture du code n’équivaut pas à un essai sur un ordinateur réel.

Les noms d’actions restent en anglais afin d’identifier exactement les clés du code ; votre panneau peut les traduire. Commandes et chemins ne sont pas traduits. Une opération destructive peut remplacer ou supprimer des données : lisez la confirmation. « À confirmer » indique une affirmation que le code seul ne garantit pas. N’utilisez pas les numéros d’anciens menus.

## À confirmer

- Disponibilité et URL publique Microsoft Store.
- Minimum officiel de RAM Linux, non imposé numériquement par le précontrôle actuel.
- Fonctionnement complet MSIX sur ARM64 ; manifeste x64.
- Formats propriétaires/versions d’export sans échantillon et revue.
- Disponibilité et conditions des sources externes depuis le réseau local.
- RAM, disque et latence IA selon matériel et choix.
- Domaine, réseau et politique institutionnelle de publication.
- Causes d’échecs concrets sans message complet et journal.
