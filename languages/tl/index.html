Mga Z39.50 / SRU serverBago

Mga piling pampublikong katalogo na sinusuri sa tunay na paghahanap: mga server lamang na may wastong MARC record ang idinaragdag sa Koha, pinakamabilis muna.

Disenyo ng OPACBago

Mga texture, bilog na sulok, wallpaper, logo, switch na maliwanag/madilim at carousel ng bagong dating, na isinusulat sa Koha matapos ang backup.

Pagmemensahe at ugnayan ng mga sistemaBago

E-mail, SMS, pansariling paghiram sa SIP2 at Z39.50 sa isang screen, na may link sa tamang pahina ng Koha at SIP2 form na sumusulat ng configuration.

Iskedyul at mga gawain sa cronBago

I-on o i-off ang bawat awtomatikong gawain at piliin ang dalas at oras. Pinananatili ang mga linyang mano-manong isinulat.

WireGuard VPNBago

Naaabot ng kawani ang kanilang interface at SSH saanman gamit ang QR code para sa telepono. Mga address lamang ng aklatan ang dumaraan sa VPN.

Libreng addressBago

Pampublikong address ng katalogo sa koha.nexus nang hindi bumibili ng domain o gumagawa ng Cloudflare account, na naibabahagi sa QR code o link. Sinusubukan pa.

Katulong na AIBago

Nagtatanong ang mga librarian sa karaniwang wika tungkol sa aklat, mambabasa at hiram. Bawat pagbabago ay mungkahi lamang na tumatakbo matapos ang Aprubahan at Isagawa.

Ang bagong control panel

Isang screen para sa bawat gawain, gamit ang mouse at keyboard.

Patakbuhin ang sudo config.sh upang buksan ang panel sa buong screen: kasalukuyang dashboard, mga card na napipindot, shortcut at command palette (ctrl+p). Ito ang tunay na mga larawan ng panel.

Dashboard ng kontrol

Kalagayan ng Koha, pinakahuling backup, bakanteng espasyo at lahat ng address ng katalogo at interface ng kawani (computer na ito, lokal na network at internet), na bawat isa ay may Buksan at Kopyahin.

Pagmemensahe at ugnayan ng mga sistema

E-mail, WhatsApp at Telegram, SMS, SIP2 at Z39.50 sa isang screen. Binubuksan ng mga link ang tamang pahina ng kawani sa Koha, tumutulong ang gabay Gmail sa SMTP form, at isinusulat ng SIP2 form ang SIPconfig.xml para sa makinang pansariling paghiram.

Mga Z39.50 / SRU server

Mga pampublikong katalogo ayon sa rehiyon at listahan ng komunidad. Nagsasagawa ang scan ng tunay na paghahanap sa bawat server at pinananatili lamang ang nagbabalik ng wastong MARC record, ayon sa bilis.

Disenyo ng OPAC

Disenyo ng pampublikong katalogo sa isang pindot: malabong salamin o pinakinis na metal, bilog na sulok, wallpaper, logo, maliwanag/madilim na switch at carousel ng bagong dating na may tunay na pabalat. Gumagawa muna ng backup.

WireGuard VPN

Pribadong WireGuard network para sa kawani: magdagdag ng telepono o laptop, i-scan ang QR code at gamitin ang interface ng kawani at SSH saanman. Hiwalay na tunnel lamang: hindi binabago ang sariling internet ng aparato.

Iskedyul at mga gawain sa cron

Bawat nakaiskedyul na gawain ay may switch, dalas at oras sa halip na text editor. Pinananatili ang mga linyang mano-manong isinulat at itinatago muna ang lumang file.

AI

Pagkakatalogong AI mula sa larawan ng pabalat at pahina ng pamagat, at katulong sa pangunahing pahina ng kawani sa Koha na sumasagot sa karaniwang wika at nagbabago lamang ng datos matapos ang Aprubahan at Isagawa.

Sentro ng backup

Nandito na lamang ang pagbabalik ng database, katabi ng MARC21 export at mga backup: wala nang hiwalay na Restore database sa pangunahing menu. I-download ang pinakabagong backup sa PC na ito, ibalik ang database mula sa backup (sinusuri muna at may pangkaligtasang kopya ng kasalukuyan), i-export ang MARC21 sa isang pindot, subukan ang backup sa pansamantalang database at kopyahin ito sa Google Drive, OneDrive, MEGA o S3 nang hakbang-hakbang.

Magsimula rito

Linux installation.

Sinusuportahan ang Debian 11/12/13 o Ubuntu 22.04/24.04 sa amd64 o arm64, at maaari ring tumakbo sa Windows gamit ang WSL 2.

Direct installer

I-download ang kasalukuyang script ng installer at patakbuhin nang may karapatang administrador.

bash 
wget https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/refs/heads/main/installer
sudo bash installer

Clone

Maaari ring itabi ang mga file ng pagsasalin sa script para magtrabaho nang offline.

bash 
git clone https://github.com/PauloFBaldiFH/koha.nexus.git
cd koha.nexus
sudo bash installer

Minimum Requirements

  • Debian 11/12/13 o Ubuntu 22.04/24.04, 64-bit
  • 4 GB RAM; inirerekomenda ang 8 GB o higit pa
  • 5 GB bakanteng espasyo; inirerekomenda ang 10 GB o higit pa
  • root o user na may karapatang sudo
  • Internet para sa mga repository ng Koha
  • Bakanteng port 80 at 8080

Pagkatapos ng install

  • Buksan ang interface ng kawani sa http://SERVER-IP:8080
  • Kumpletuhin ang Koha Web Installer
  • Gumawa ng super librarian sa dashboard
  • Nasa http://SERVER-IP:80 ang pampublikong katalogo
  • Buksan muli ang dashboard gamit ang sudo config.sh

Pag-install

I-right-click ang Start, piliin ang Terminal (Admin) at i-click ang Yes. I-paste ang command sa itaas at pindutin ang Enter.

Use your own Windows account. If Windows asks for another person's password, sign in to an administrator account first and run it there: Debian, the shortcuts and the restart step are created for the account that runs the installer.
Paano i-enable ang Virtualization:

I-restart at pumunta sa BIOS:

  • Del ou F2 — ASUS, Gigabyte, MSI, ASRock, Acer
  • F10 ou Esc — HP / Compaq
  • F2 ou F12 — Dell
  • F1, F2 ou Enter — Lenovo

I-enable ang Intel VT-x o AMD SVM.

Gamitin ang Windows Advanced Startup.
