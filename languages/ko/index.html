자동 업데이트

GitHub에서 안전한 업데이트.

Z39.50 / SRU 서버

실제 검색으로 검증한 공개 목록: 유효한 MARC 레코드를 반환하는 서버만 Koha에 추가하며 빠른 서버가 먼저입니다.

OPAC 외관

질감, 둥근 모서리, 배경화면, 로고, 밝게/어둡게 전환, 신착 도서 캐러셀을 backup 후 Koha에 기록합니다.

메시지와 상호 운용

이메일, SMS, SIP2 무인 대출, Z39.50을 한 화면에 모으고 정확한 Koha 페이지 링크와 설정을 기록하는 SIP2 양식을 제공합니다.

일정과 cron 작업

각 자동 작업을 켜거나 끄고 주기와 시간을 선택합니다. 직접 작성한 줄은 유지합니다.

WireGuard VPN

직원은 휴대전화 QR 코드로 어디서나 직원 화면과 SSH에 접속합니다. 도서관 주소만 VPN을 통과합니다.

무료 주소

도메인 구매나 Cloudflare 계정 없이 koha.nexus의 공개 목록 주소를 만들고 QR 코드 또는 링크로 공유합니다. 아직 테스트 중입니다.

AI 도우미

사서는 책, 회원, 대출에 관해 일상 언어로 질문합니다. 모든 변경은 제안으로 표시하며 승인 후 실행해야 적용됩니다.

새로운 제어판

마우스와 키보드로 모든 작업을 한 화면에서.

sudo config.sh를 실행하면 전체 화면 패널이 열립니다. 실시간 대시보드, 클릭 가능한 카드, 단축키, 명령 팔레트(ctrl+p)를 제공합니다. 아래는 실제 패널 화면입니다.

제어 대시보드

Koha 상태, 최근 backup, 디스크 여유 공간, 목록과 직원 화면의 모든 주소(현재 컴퓨터, 내부망, 인터넷)를 표시하며 각각 열기와 복사 버튼이 있습니다.

메시지와 상호 운용

이메일, WhatsApp과 Telegram, SMS, SIP2, Z39.50을 한 화면에서 설정합니다. 링크는 정확한 Koha 직원 페이지를 열고 Gmail 도움말은 SMTP 양식 작성을 돕고 SIP2 양식은 무인 대출기용 SIPconfig.xml을 기록합니다.

Z39.50 / SRU 서버

지역별 공개 목록과 커뮤니티 목록. 각 서버에서 실제 검색을 수행하고 유효한 MARC 레코드를 반환하는 서버만 속도순으로 유지합니다.

OPAC 외관

한 번의 클릭으로 공개 목록 외관 설정: 반투명 유리나 브러시 금속, 둥근 모서리, 배경화면, 로고, 밝게/어둡게 전환, 실제 표지의 신착 도서 캐러셀. 먼저 backup을 만듭니다.

WireGuard VPN

직원 전용 WireGuard 사설망: 휴대전화나 노트북을 추가하고 QR 코드를 스캔하면 어디서나 직원 화면과 SSH를 사용할 수 있습니다. 분할 터널만 사용하므로 기기 자체 인터넷은 변경하지 않습니다.

일정과 cron 작업

텍스트 편집기 대신 각 예약 작업을 스위치, 주기, 시간으로 설정합니다. 직접 작성한 줄은 유지하고 이전 파일을 먼저 저장합니다.

AI

표지와 표제지 사진으로 AI 목록을 작성하고 Koha 직원 홈의 도우미가 일상 언어로 답합니다. 데이터는 승인 후 실행한 경우에만 변경합니다.

Backup 센터

데이터베이스 복원은 이제 MARC21 내보내기와 backup 기능 옆에만 있습니다. 기본 메뉴에 별도 Restore database 옵션은 없습니다. 최신 backup을 이 컴퓨터에 내려받고, backup으로 복원(먼저 테스트하고 현재 데이터의 안전 사본 생성), 한 버튼으로 MARC21 내보내기, 임시 데이터베이스에서 backup 테스트, Google Drive·OneDrive·MEGA·S3로 복사를 단계별로 수행합니다.

여기서 시작하세요

몇 가지 명령으로 Linux 설치.

프로젝트는 amd64 또는 arm64의 Debian 11/12/13이나 Ubuntu 22.04/24.04를 지원하며 Windows에서도 WSL 2로 실행할 수 있습니다.

직접 설치

현재 설치 스크립트를 내려받아 관리자 권한으로 실행하세요.

bash 
wget https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/refs/heads/main/installer
sudo bash installer

리포지토리 복제

오프라인 작업을 위해 번역 파일을 스크립트 옆에 보관할 수 있습니다.

bash 
git clone https://github.com/PauloFBaldiFH/koha.nexus.git
cd koha.nexus
sudo bash installer

최소 요구 사항

  • Debian 11/12/13 또는 Ubuntu 22.04/24.04, 64-bit
  • 4 GB RAM, 8 GB 이상 권장
  • 5 GB 여유 공간, 10 GB 이상 권장
  • root 또는 sudo 권한 사용자
  • Koha 저장소에 접근할 인터넷
  • 80 및 8080 포트 사용 가능

설치 후

  • 직원 화면 열기: http://SERVER-IP:8080
  • Koha Web Installer 완료
  • 대시보드에서 최고 사서 계정 생성
  • 공개 목록: http://SERVER-IP:80
  • 언제든 sudo config.sh로 대시보드 다시 열기
