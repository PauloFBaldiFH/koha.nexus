Z39.50 / SRU 服务器

精选公共目录均经过实际检索测试：仅将返回有效 MARC 记录的服务器加入 Koha，速度最快的优先。

OPAC 外观

纹理、圆角、壁纸、标志、明暗切换和新书轮播，先创建 backup 再写入 Koha。

消息与互操作

电子邮件、SMS、SIP2 自助借还和 Z39.50 集中在同一屏幕，链接直达 Koha 相应页面，SIP2 表单负责写入配置。

计划与 cron 任务

启用或停用每项自动任务，设置频率和时间。手写行保持不变。

WireGuard VPN

工作人员可通过手机二维码，随处访问工作人员界面和 SSH。仅图书馆地址经过 VPN。

免费地址

无需购买域名或开设 Cloudflare 账户，即可在 koha.nexus 获得公共目录地址，并通过二维码或链接分享。目前仍在测试。

AI 助手

馆员可用日常语言询问图书、读者和借阅情况。任何更改都会先作为提案，仅在批准并执行后运行。

全新控制面板

每项任务一个屏幕，支持鼠标和键盘。

运行 sudo config.sh，面板即全屏打开：实时仪表板、可点击卡片、快捷键和命令面板（ctrl+p）。以下为面板的实际截图。

在交互式手册中探索→

控制仪表板

Koha 状态、最新 backup、可用磁盘空间，以及目录和工作人员界面的所有地址（本机、局域网、互联网），每个地址均有打开和复制按钮。

消息与互操作

在同一屏幕中配置电子邮件、WhatsApp 和 Telegram、SMS、SIP2 和 Z39.50。链接直达 Koha 相应的工作人员页面，Gmail 速查指南帮助填写 SMTP 表单，SIP2 表单为自助借还设备写入 SIPconfig.xml。

Z39.50 / SRU 服务器

按地区整理的公共目录及社区列表。扫描对每个服务器执行实际检索，仅保留返回有效 MARC 记录的服务器，并按速度排序。

OPAC 外观

一键设置公共目录外观：磨砂玻璃或拉丝金属、圆角、壁纸、标志、明暗切换，以及带真实封面的新书轮播。首先创建 backup。

WireGuard VPN

工作人员专用 WireGuard 网络：添加手机或笔记本电脑，扫描二维码，即可随处使用工作人员界面和 SSH。仅使用分流隧道：设备自身的互联网连接保持不变。

计划与 cron 任务

每个定时任务均有开关、频率和时间设置，无需使用文本编辑器。保留手写行，并先保存旧文件。

人工智能

根据封面和题名页照片进行 AI 编目，并在 Koha 工作人员首页提供助手，用日常语言回答问题，仅在批准并执行后修改数据。

Backup 中心

数据库恢复现在仅位于此处，与 MARC21 导出和 backup 功能并列：主菜单不再单设 Restore database。将最新 backup 下载至此电脑，从 backup 恢复数据库（先测试并保存当前数据库的安全副本），一键导出 MARC21 记录，在临时数据库中测试 backup，并逐步复制到 Google Drive、OneDrive、MEGA 或 S3。

从这里开始

几个命令完成 Linux 安装。

项目支持 amd64 或 arm64 架构的 Debian 11/12/13 或 Ubuntu 22.04/24.04，也可通过 WSL 2 在 Windows 上运行。

直接安装

下载当前安装脚本，以管理员权限运行。

bash 
wget https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/refs/heads/main/installer
sudo bash installer

克隆仓库

也可将翻译文件与脚本放在一起，以供离线使用。

bash 
git clone https://github.com/PauloFBaldiFH/koha.nexus.git
cd koha.nexus
sudo bash installer

最低要求

  • Debian 11/12/13 或 Ubuntu 22.04/24.04，64-bit
  • 4 GB RAM；建议 8 GB 或更多
  • 5 GB 可用空间；建议 10 GB 或更多
  • root 或具有 sudo 权限的用户
  • 可访问 Koha 软件仓库的互联网连接
  • 80 和 8080 端口可用

安装后

  • 在 http://SERVER-IP:8080 打开工作人员界面
  • 完成 Koha Web Installer
  • 通过仪表板创建超级馆员账户
  • 公共目录位于 http://SERVER-IP:80
  • 随时通过 sudo config.sh 重新打开仪表板
