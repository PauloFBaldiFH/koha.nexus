Windows + WSL 2

Windows PCでKohaを実行します。

自動更新

GitHubからの安全な更新。

Z39.50 / SRU サーバー

公開目録を選定し実際に検索して検証。有効な MARC レコードを返すサーバーだけを Koha に追加し、速い順に並べます。

OPAC の外観

テクスチャー、角丸、壁紙、ロゴ、ライト／ダーク切替、新着カルーセルを、backup 作成後に Koha に書き込みます。

メッセージと相互運用

メール、SMS、SIP2 自動貸出、Z39.50 をひとつの画面にまとめ、Koha の該当ページへのリンクと設定を書き込む SIP2 フォームを備えます。

スケジュールと cron ジョブ

自動ジョブごとに有効・無効、頻度、時刻を選択します。手書きの行は保持します。

WireGuard VPN

電話用 QR コードで職員画面と SSH にどこからでも接続できます。VPN を通るのは図書館のアドレスだけです。

無料アドレス

ドメイン購入や Cloudflare アカウントなしで、koha.nexus 上に公開目録のアドレスを取得し、QR コードやリンクで共有できます。現在テスト中です。

AI アシスタント

司書が本、利用者、貸出について自然な言葉で質問できます。変更はすべて提案され、承認して実行した場合だけ動作します。

新しいコントロールパネル

マウスとキーボードで、各作業をひとつの画面から。

sudo config.sh を実行すると全画面のパネルが開きます。リアルタイムのダッシュボード、クリックできるカード、ショートカット、コマンドパレット（ctrl+p）を備えています。以下は実際の画面です。

インタラクティブマニュアルで見る→

管理ダッシュボード

Koha の状態、最新の backup、空き容量、目録と職員画面の全アドレス（このパソコン、館内ネットワーク、インターネット）を表示し、それぞれ開く・コピーするボタンがあります。

メッセージと相互運用

メール、WhatsApp と Telegram、SMS、SIP2、Z39.50 をひとつの画面で設定します。リンクは Koha の該当職員ページを開き、Gmail の手引きは SMTP 入力を助け、SIP2 フォームは自動貸出機用の SIPconfig.xml を書き込みます。

Z39.50 / SRU サーバー

地域別の公開目録とコミュニティ一覧。各サーバーで実際に検索し、有効な MARC レコードを返すものだけを速度順に残します。

OPAC の外観

公開目録の外観をワンクリックで設定します。すりガラスやヘアライン金属、角丸、壁紙、ロゴ、ライト／ダーク切替、本物の書影付き新着カルーセル。最初に backup を作成します。

WireGuard VPN

職員専用の WireGuard ネットワーク。電話やノートパソコンを追加し QR コードを読めば、どこからでも職員画面と SSH が使えます。分割トンネルのみで、端末自身のインターネット接続は変えません。

スケジュールと cron ジョブ

テキスト編集の代わりに、各定期ジョブをスイッチ・頻度・時刻で設定します。手書きの行を保持し、古いファイルを先に保存します。

AI

表紙と標題紙の写真による AI 目録作成と、職員ホーム画面のアシスタント。自然な言葉で回答し、承認して実行した場合のみデータを変更します。

Backup センター

データベースの復元は MARC21 エクスポートと backup 機能の横にまとめられ、メインメニューに独立した Restore database はありません。最新の backup をこのパソコンに保存し、backup から復元（先にテストし、現在の安全用コピーを作成）、MARC21 のワンボタン出力、一時データベースでの backup テスト、Google Drive・OneDrive・MEGA・S3 へのコピーを順に行えます。

ここから開始

いくつかのコマンドでLinuxをインストール。

amd64 または arm64 の Debian 11/12/13 と Ubuntu 22.04/24.04 に対応し、Windows でも WSL 2 経由で動作します。

直接インストーラー

現在のインストールスクリプトをダウンロードし、管理者権限で実行します。

bash 
wget https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/refs/heads/main/installer
sudo bash installer

リポジトリのクローン

翻訳ファイルをスクリプトと同じ場所に置けば、オフラインでも使えます。

bash 
git clone https://github.com/PauloFBaldiFH/koha.nexus.git
cd koha.nexus
sudo bash installer

最小要件

  • Debian 11/12/13 または Ubuntu 22.04/24.04、64-bit
  • RAM 4 GB。8 GB 以上を推奨
  • 空き容量 5 GB。10 GB 以上を推奨
  • root、または sudo 権限のあるユーザー
  • Koha リポジトリーに接続できるインターネット
  • ポート 80 と 8080 が利用可能

インストール後

  • 職員画面を http://SERVER-IP:8080 で開く
  • Koha Web Installer を完了する
  • ダッシュボードからスーパー司書を作成する
  • 公開目録は http://SERVER-IP:80
  • いつでも sudo config.sh でダッシュボードを開く

インストール

スタートを右クリックして ターミナル (管理者) を選び、はいをクリックします。上のコマンドを貼り付けて Enter を押します。

Use your own Windows account. If Windows asks for another person's password, sign in to an administrator account first and run it there: Debian, the shortcuts and the restart step are created for the account that runs the installer.
