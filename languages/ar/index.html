تحديث تلقائي

تحديثات آمنة من GitHub.

خوادم Z39.50 / SRUجديد

فهارس عامة مختارة تُختبر ببحث حقيقي: لا يُضاف إلى Koha إلا خادم يعيد تسجيلات MARC صالحة، الأسرع أولًا.

مظهر OPACجديد

خامات وزوايا مستديرة وخلفية وشعار ومبدّل فاتح/داكن وعرض دوار للجديد، تُكتب في Koha بعد إنشاء backup.

المراسلة والتشغيل البينيجديد

البريد الإلكتروني وSMS والإعارة الذاتية SIP2 وZ39.50 في شاشة واحدة، مع روابط لصفحة Koha الصحيحة ونموذج SIP2 يكتب الإعدادات.

الجداول ومهام cronجديد

فعّل كل مهمة تلقائية أو عطّلها وحدد التكرار والوقت. تُحفظ الأسطر المكتوبة يدويًا.

WireGuard VPNجديد

يصل الموظفون إلى واجهتهم وSSH من أي مكان برمز QR لهواتفهم. تمر عناوين المكتبة فقط عبر VPN.

عنوان مجانيجديد

عنوان فهرس عام على koha.nexus دون شراء نطاق أو فتح حساب Cloudflare، يُشارك برمز QR أو رابط. ما زال قيد الاختبار.

مساعد ذكيجديد

يسأل أمناء المكتبات بلغة عادية عن الكتب والقراء والإعارات. كل تغيير مقترح لا يُنفَّذ إلا بعد الموافقة والتنفيذ.

لوحة التحكم الجديدة

شاشة لكل مهمة، بالفأرة ولوحة المفاتيح.

شغّل sudo config.sh لتفتح اللوحة بملء الشاشة: لوحة حالة مباشرة وبطاقات قابلة للنقر واختصارات ولوحة أوامر (ctrl+p). هذه لقطات فعلية للوحة.

لوحة التحكم

حالة Koha وآخر backup والمساحة الحرة وجميع عناوين الفهرس وواجهة الموظفين (هذا الحاسوب والشبكة المحلية والإنترنت)، ولكل منها زرا فتح ونسخ.

المراسلة والتشغيل البيني

البريد الإلكتروني وWhatsApp وTelegram وSMS وSIP2 وZ39.50 في شاشة واحدة. تفتح الروابط صفحة موظفي Koha الصحيحة، ويساعد دليل Gmail في نموذج SMTP، ويكتب نموذج SIP2 ملف SIPconfig.xml لجهاز الإعارة الذاتية.

خوادم Z39.50 / SRU

فهارس عامة حسب المنطقة وقائمة المجتمع. يُجري الفحص بحثًا حقيقيًا بكل خادم، ويحتفظ فقط بما يعيد تسجيلة MARC صالحة، مرتبة حسب السرعة.

مظهر OPAC

مظهر الفهرس العام بنقرة واحدة: زجاج مصنفر أو معدن مصقول وزوايا مستديرة وخلفية وشعار ومبدّل فاتح/داكن وعرض دوار للجديد بأغلفة حقيقية. يُنشأ backup أولًا.

WireGuard VPN

شبكة WireGuard خاصة للموظفين: أضف هاتفًا أو حاسوبًا محمولًا وامسح QR لتعمل واجهة الموظفين وSSH من أي مكان. نفق منقسم فقط: لا يتغير اتصال الجهاز بالإنترنت.

الجداول ومهام cron

لكل مهمة مجدولة مفتاح تشغيل وتكرار ووقت بدل محرر النصوص. تُحفظ الأسطر المكتوبة يدويًا ويُحفظ الملف القديم أولًا.

الذكاء الاصطناعي

فهرسة بالذكاء الاصطناعي من صور الغلاف وصفحة العنوان، ومساعد في الصفحة الرئيسية لموظفي Koha يجيب بلغة عادية ولا يغير البيانات إلا بعد الموافقة والتنفيذ.

مركز backup

استعادة قاعدة البيانات هنا فقط، بجانب تصدير MARC21 وإجراءات backup: لم يعد بالقائمة الرئيسية خيار Restore database مستقل. نزّل أحدث backup إلى هذا الحاسوب، واستعد القاعدة منه (بعد اختباره وحفظ نسخة أمان للحالية)، وصدّر MARC21 بزر واحد، واختبر backup في قاعدة مؤقتة وانسخه إلى Google Drive أو OneDrive أو MEGA أو S3 خطوة بخطوة.

تثبيت لينكس ببضعة أوامر.

يدعم المشروع Debian 11/12/13 أو Ubuntu 22.04/24.04 على amd64 أو arm64، ويمكن تشغيله على Windows عبر WSL 2.

المثبت المباشر

نزّل نص التثبيت الحالي وشغّله بصلاحيات المسؤول.

bash 
wget https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/refs/heads/main/installer
sudo bash installer

استنساخ المستودع

يمكن حفظ ملفات الترجمة بجانب النص للعمل دون اتصال.

bash 
git clone https://github.com/PauloFBaldiFH/koha.nexus.git
cd koha.nexus
sudo bash installer

الحد الأدنى من المتطلبات

  • Debian 11/12/13 أو Ubuntu 22.04/24.04، 64-bit
  • ذاكرة RAM بسعة 4 GB؛ يُنصح بـ 8 GB أو أكثر
  • مساحة حرة 5 GB؛ يُنصح بـ 10 GB أو أكثر
  • root أو مستخدم بصلاحيات sudo
  • اتصال بالإنترنت لمستودعات Koha
  • المنفذان 80 و8080 متاحان

بعد التثبيت

  • افتح واجهة الموظفين على http://SERVER-IP:8080
  • أكمل Koha Web Installer
  • أنشئ حساب أمين المكتبة الأعلى عبر اللوحة
  • الفهرس العام على http://SERVER-IP:80
  • أعد فتح اللوحة باستخدام sudo config.sh

التثبيت

انقر بزر الماوس الأيمن على ابدأ واختر Terminal (Admin) ثم انقر نعم. الصق الأمر أعلاه واضغط Enter.

Use your own Windows account. If Windows asks for another person's password, sign in to an administrator account first and run it there: Debian, the shortcuts and the restart step are created for the account that runs the installer.
كيفية تمكين المحاكاة الافتراضية:

أدخل إعدادات BIOS.

  • Del ou F2 — ASUS, Gigabyte, MSI, ASRock, Acer
  • F10 ou Esc — HP / Compaq
  • F2 ou F12 — Dell
  • F1, F2 ou Enter — Lenovo

قم بتمكين Intel VT-x أو AMD SVM.

Feriados Brasileiros Feriados nacionais e datas móveis, com opção para inserir os municipais. PRE-CALENDARIO
Relatórios de Censo Indicadores baseados nos dados do Koha para MEC, INEP, IBGE e SNBP. PRE-CENSO
