# Website source

The root `index.html` is English. Each other language supported by the panel
has a directory under `languages/` named after its existing dictionary code,
for example `languages/pt/`, `languages/es/` or `languages/ja/`. Every directory
contains its homepage and `preview/index.html`. English stays at `index.html`
and `preview/index.html` in the repository root. Only generated website pages
move: the panel dictionaries in `lang/` remain unchanged.
Portuguese pages use `lang="pt-BR"`; simplified Chinese uses `lang="zh-Hans"`.
Arabic and Persian use right-to-left layout.

Edit these sources rather than generated HTML:

- `templates/home.html` and `templates/preview.html`: shared page structure.
- `locales/<code>.json`: hand-written homepage and manual navigation text.
- `assets/home.css`, `assets/home.js` and `../preview/assets/`: shared styling
  and interactive behaviour.
- `../preview/manual/en.json` and `../preview/manual/pt-BR.json`: detailed guides.

Regenerate the panel data and every page together:

```sh
python3 export_docs_preview.py
python3 export_docs_preview.py --check
python3 -m pytest -q panel/tests/test_docs_preview.py panel/tests/test_site_languages.py
```

For homepage or navigation changes alone, `python3 export_site.py` regenerates
only HTML. Both generators are deterministic. The website workflow checks the
committed pages, language links, alternate links, assets and placeholder counts.
It does not deploy or create releases.

`export_site.py` also writes `sitemap.xml` and `robots.txt` at the repository
root and gives every page a canonical link, Open Graph tags and, on homepages
only, SoftwareApplication data. Search titles and descriptions come from the
optional `seo` group of a locale (English and Portuguese have one); other
languages keep `page_title`/`page_description` and the manual title. Submitting
the sitemap to Google Search Console is done by hand after merging.

Language links work without JavaScript. The manual selector preserves the open
section. On the directory root (`/`), a saved manual choice takes priority over the browser's ordered language preferences. Unsupported preferences fall back to English.
Direct translated page paths and the explicit English `index.html` take priority
over browser preferences. Only language-selector anchors save a manual choice;
clicking other page content does not change that preference. Manual
choices are saved when browser storage is available; detection still works
when storage is blocked. Legacy
`?lang=br`, `?lang=pt` and other supported query links navigate to the matching
language directory under `languages/`. `hreflang` links refer to the public `https://koha.nexus/`
URLs, while navigation and asset links are relative so local previews also work.

The detailed guides remain English outside English and Portuguese for this
change. Each untranslated guide displays a notice in the selected language.
Their translation is a follow-up after this change is merged, in reviewable
batches of about 20 guides. The simulator continues to use the panel's own
translation caches. Existing Windows installation instructions and commands
are preserved; no installer, package or release is generated by these scripts.

The translated public URLs now use `/languages/<code>/` and
`/languages/<code>/preview/`. The old root paths such as `/pt/` are no longer
generated. Update external bookmarks or configure redirects on the hosting
service if those old URLs have already been published. No hosting redirect or
deployment is configured by this generator.
