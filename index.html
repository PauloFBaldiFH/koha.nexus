Start here

Linux installation in a few commands.

The project targets Debian 11/12/13 or Ubuntu 22.04/24.04 on amd64 or arm64 architecture, and can also run on Windows via WSL 2.

Direct installer

Download the current installer script and run it with administrative privileges.

bash 
wget https://raw.githubusercontent.com/PauloFBaldiFH/koha.nexus/refs/heads/main/installer
sudo bash installer

Clone the repository

You can also keep translation files alongside the script to work offline.

bash 
git clone https://github.com/PauloFBaldiFH/koha.nexus.git
cd koha.nexus
sudo bash installer

Minimum requirements

  • Debian 11/12/13 or Ubuntu 22.04/24.04, 64-bit
  • 2 GB of RAM; 4 GB or more recommended
  • 5 GB free space; 10 GB or more recommended
  • root or user with sudo privileges
  • Internet access for Koha repositories
  • Ports 80 and 8080 available

After installation

  • Open the staff interface at http://SERVER-IP:8080
  • Complete the Koha Web Installer
  • Create your super librarian via the dashboard
  • The public catalog is at http://SERVER-IP:80
  • Reopen the dashboard anytime with sudo config.sh

How to enable Virtualization in BIOS:

Restart your PC and repeatedly press F2 or Del during boot to enter BIOS/UEFI. Locate Intel Virtualization Technology (VT-x) or AMD SVM / AMD-V (usually found under CPU Configuration, Advanced, or Overclocking), switch it to Enabled, then press F10 to save and restart.

Library tools

More than installing Koha: taking care of the collection.

The dashboard tools utilize Koha's own mechanisms and follow a strict protection flow with locking, previewing, confirmation, and verified backups before any data is altered.

Magic Import Tool

A single entry point for spreadsheets, MARC files, compressed archives, collections, items, patrons, and circulation data.

CSV • TSV • XLSX • ODS • DBF • MARC21 • MARCXML

Undo MARC import

Allows reverting a batch import in a controlled manner, preserving catalog integrity.

SQL Reports Pack

Read-only reports for loans, overdues, acquisitions, missing barcodes, items never borrowed, and lost items.

Category rollover

Moves patrons between categories using criteria defined by the library, with a dry run before execution.

Data quality

Runs catalog inconsistency checks without altering the actual records.

Privacy & GDPR/LGPD

Anonymizes old borrowing histories and securely deletes expired patrons that meet defined criteria.

Protection by default: Operations that alter data follow a shared lock with backups, previews, confirmations, and a verified PRE-* copy before making changes.
Cataloging

PHA, Cutter-Sanborn, DDC, and AI working alongside the cataloger.

The project brings together helper tools for classification, author notation, Cutter calculation, and safe MARC record replacement, without removing the professional review step.

Author notation

Uses the library's own PHA or Cutter-Sanborn table and highlights numbers already used in the catalog.

DDC lookup

Searches by number or subject from a local copy of the library's DDC, integrated with the cataloging form.

Cutter Calculator

Calculates notation, suggests classes based on the catalog, and can auto-fill 090, 092, or the item call number field.

Replace a MARC record

Replaces a record via MARC or XML through preview, transactional lock, and saving the previous version.

AI cataloging

Receives photos of the cover, title page, and verso, generating a record proposal applying cataloging rules before human review.

Local or Cloud Models

Supports OpenAI-compatible services and local models via Ollama or LM Studio, without storing tokens in the dashboard.

AI Cataloging Workflow

  • Book photos and optional instructions
  • Structured JSON response
  • Application of AACR2/ISBD and MARC rules
  • Review by the librarian/operator
  • Mandatory preview before saving
  • Record and model response can be preserved for auditing

Important Principle

The AI functions as a cataloging assistant. The generated proposal is reviewed and only then sent to Koha. The project also includes strict prompts to prevent hallucinating fields not supported by the photographs or context.

Power Failure

The project includes verification after an unclean reboot, creates a new backup, and updates the index when necessary. On Windows, the safe shutdown routine attempts to stop Koha gracefully before the system shuts down.

Uninstallation is destructive: The uninstall.sh script permanently removes Koha, databases, local backups, and configurations. Backup your data off-server before using it.
